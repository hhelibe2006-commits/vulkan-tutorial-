== 差异

与最初的教程相比，本版本教程讲授的是最新的概念：

* 以 Vulkan 1.4 为基线
* 用动态渲染取代渲染通道
* 时间线信号量
* 以 link:https://shader-slang.org/[Slang] 作为主要着色语言
* 现代 C++（20）
* link:https://github.com/KhronosGroup/Vulkan-Hpp[Vulkan-Hpp] 配合 link:https://en.wikipedia.org/wiki/Resource_acquisition_is_initialization[RAII]

它还包含 Vulkan 用法澄清、改进的同步机制以及全新内容。

== 安装依赖

本项目提供脚本，帮助你安装所需的依赖：

=== Linux
运行以下命令在 Linux 上安装依赖：
[source,bash]
----
./scripts/install_dependencies_linux.sh
----

该脚本会检测你的包管理器（apt、dnf、pacman），并安装所需依赖，包括：
* 构建基础工具（gcc、cmake、ninja-build）
* GLFW、GLM、tinyobjloader、stb
* X Window System 相关依赖

它还提供了安装 Vulkan SDK 的说明。

=== Windows
运行以下命令在 Windows 上安装依赖：
[source,batch]
----
scripts\install_dependencies_windows.bat
----

该脚本使用 vcpkg 安装所需依赖，包括：
* GLFW、GLM、tinyobjloader、stb

你还需要从 https://vulkan.lunarg.com/ 单独安装 Vulkan SDK。
