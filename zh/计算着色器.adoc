== 介绍

在本章中，我们将探讨计算着色器。此前所有章节都讨论了 Vulkan 管线中的传统图形部分。但与 OpenGL 等旧 API 不同，Vulkan 强制要求支持计算着色器。这意味着无论 Vulkan 实现是高端桌面 GPU 还是低功耗嵌入式设备，您都可以使用它。

这开启了图形处理器通用计算（GPGPU）的新篇章，无论应用程序运行在何处。GPGPU意味着您可以在GPU上执行通用计算，而这传统上一直是CPU的专属领域。但随着GPU变得越来越强大和灵活，许多原本需要CPU通用计算能力的工作负载现在都可以在GPU上实时完成。

GPU的计算能力可以应用于图像处理、可见性测试、后期处理、高级光照计算、动画、物理模拟（例如粒子系统）等等。甚至还可以将计算能力用于无需任何图形输出的非视觉计算工作，例如数值计算或人工智能相关任务。这被称为“无头计算”。

== 优势

在GPU上进行计算密集型运算有诸多优势。最显而易见的优势是减轻CPU的负担。其次，无需在CPU主内存和GPU内存之间传输数据。所有数据都可以保留在GPU上，无需等待从主内存缓慢传输。

除此之外，GPU 还高度并行化，有些 GPU 甚至拥有数万个小型计算单元。这使得它们通常比只有少量大型计算单元的 CPU 更适合高度并行的工作流程。
