= 环境搭建

== 简介

在传统图形编程中，环境搭建是一次性、单向的过程：装好编译器（GCC/Clang/MSVC）、配置调试器，再把 IDE 指向 Vulkan SDK。除了你在构建时告诉它们的信息以外，这些工具对你的项目一无所知。

AI 辅助的搭建则多加了一层：一个**上下文桥（Context Bridge）**，让模型能够看到你的代码库、你的构建配置，并且（通过 MCP）看到 Vulkan 规范和你 GPU 的实际限制。本章介绍这种搭建方式是什么样子，以及为什么值得花这些功夫。

== 它解决的问题：上下文鸿沟

使用 AI 编码工具时最常见的挫败感，就是我们所说的**上下文鸿沟（context gap）**。你让助手「加一个新的图像屏障」，它却给回一段使用 `VkImageMemoryBarrier`（Vulkan 1.0）的通用代码片段，而不是你的引擎实际在用的 `VkDependencyInfo`（Vulkan 1.3）模式。它还可能把改动放进错误的文件，不符合你引擎的约定。修复这些问题花的时间比你亲自写还多，因为现在你是在事后解释引擎的抽象，而不是事先。

配置得当的环境会沿三个方向收窄这个鸿沟：

- **语法上下文**——IDE 自身对代码库的理解（它的 AST、宏展开、包含的头文件）。如果 AI 知道你的 `Texture` 类包装了 `vk::raii::Image`，它就不会给出那些根本编译不过的裸指针操作。
- **语义上下文**——通过模型上下文协议（MCP）与 Vulkan 规范和 `vk.xml` 注册表建立实时连接，这样模型可以查证某个位掩码或扩展究竟是什么意思，而不是依赖记下来的训练数据。
- **运行时上下文**——访问 `vulkaninfo` 的输出或你自己引擎的日志，让模型能推断某个管线创建调用在你的具体硬件上为何失败，而不是在抽象层面猜测。

== 该委托多少

这里值得把失败模式说清楚：一个被要求「去写引擎」又无人监督的代理，产出的代码你不理解、也无法维护。有用的中间路线是委托具体、边界明确的任务并审阅输出，而不是把架构决策整体交出去。

这种中间路线的两个例子：

**样板代码。** 一个 `VkGraphicsPipelineCreateInfo` 能写到 200 行。描述意图——「一个用于延迟 G-buffer 通道的管线，开启 4x MSAA 和深度测试」——让模型把结构体填好，然后审阅结果，通常比手打更快，正确性也毫不逊色，前提是你真的读了返回的内容。

**规范查询。** 如果你在排查同步问题，可以向有 MCP 访问权限的助手提问，比如「考虑到我们使用了 `VK_IMAGE_LAYOUT_ATTACHMENT_OPTIMAL`，在 Adreno 750 上转换到 `SHADER_READ_ONLY_OPTIMAL` 需要哪些访问掩码？」，而不必自己切到规范文档去翻。这里的价值在于检索，而非推理——它替你省下一次查阅，而不是一个决策。

== IDE 助手与独立代理

工具大致分为两类，而多数 Vulkan 工作流最终两类都会用。**IDE 内助手**（JetBrains AI、GitHub Copilot）处在你的内层循环里——自动补全、快速解释光标下的代码。**面向任务的代理**（Goose、Aider）处在你的外层循环里——你交给它「把描述符管理迁移到描述符缓冲区」这样的任务，它跨文件修改、运行编译器，并反复迭代直到构建通过。

随着 IDE 原生加入越来越多代理式功能，这两类工具之间的界线正在模糊，但这个区分仍然是思考某个任务该用哪种工具的有效方式。

== 第一步：构建 Vulkan MCP 服务器

在进入各平台章节之前，有一个前提：构建 **mcp-Vulkan** 服务器。后面每一章都假设它已经构建好，并让各自的工具指向 `/path/to/mcp-Vulkan/vulkan/build/index.js`。

你需要 **Node.js**（LTS）和 **npm**。如果还没有，请从 link:https://nodejs.org/[nodejs.org] 获取 LTS 安装包。

[source,bash]
----
# Clone the repository
git clone https://github.com/gpx1000/mcp-Vulkan.git

# The package.json lives in the vulkan/ subdirectory
cd mcp-Vulkan/vulkan

# Install dependencies and build
npm install
npm run build
----

请记下 `mcp-Vulkan` 目录的绝对路径（在该目录里运行 `pwd`）——每个平台章节在注册服务器时都需要它。
