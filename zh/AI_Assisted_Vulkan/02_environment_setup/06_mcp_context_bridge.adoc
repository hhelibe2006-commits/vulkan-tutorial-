= 上下文桥：模型上下文协议（MCP）

== 简介

即便是 **Qwen 3-Coder** 这样强的模型也有硬性限制：它的训练数据有截止日期。在那之后发布的 Vulkan 扩展它无从知晓，它看不到你的本地文件系统，除非有人告诉它，否则它也无法得知你 GPU 的 `maxSamplerAnisotropy` 上限。**Model Context Protocol（MCP，模型上下文协议）** 是一项开放标准，让 AI 能够查询这类事实依据——你的本地环境，或 Vulkan 注册表这样的外部数据源——而不是从记住的训练数据里去猜。

== 为什么这在实践中很重要

问一个通用模型「怎么为我们的 `Renderer` 类实现网格着色器？」，如果它的默认假设停留在 Vulkan 1.0，它甚至可能不知道网格着色器是什么。有了 MCP，一个指向 **mcp-Vulkan** 服务器的助手就能查询真实的注册表，捡起那些训练数据里并不可靠的新特性——网格着色器、光线追踪、描述符缓冲区。Vulkan MCP 服务器还会提供示例、指南条目、手册页等参考资料，所以助手不会被限制在它在训练时恰好见过的生态子集里。

== mcp-Vulkan 服务器

**mcp-Vulkan** 是一个开源的 MCP 服务器，提供搜索 Vulkan 文档、从当前规范中提取特定主题的工具。

没有它时一种常见的失败：助手建议使用 `vkCreateDescriptorPool` 这类已废弃的调用，却不带现代特性所需的 `pNext` 结构。接上 mcp-Vulkan 之后，你可以让它把上下文设定到某个具体的 Vulkan 版本（「Vulkan 1.3，然后列出该版本中已成为核心的扩展」），从而得到一个基于该版本真实规范的答案，而不是跨版本的某种平均值。

=== 构建服务器

如果还没构建过，参见 xref:AI_Assisted_Vulkan/02_environment_setup/01_introduction.adoc#_first_step_building_the_vulkan_mcp_server[第一步：构建 Vulkan MCP 服务器]。那里讲了克隆仓库并在 `mcp-Vulkan/vulkan/` 中运行 `npm install && npm run build`。

=== 把 mcp-Vulkan 接到 Goose 上

通过编辑配置文件把这个服务器注册为 Goose 扩展——macOS/Linux 上是 `~/.config/goose/config.yaml`，Windows 上是 `%APPDATA%\goose\config.yaml`（通常是 `C:\Users\<YourUser>\AppData\Roaming\goose\config.yaml`）。

在 `extensions:` 下加入以下内容，把 `/path/to/` 换成实际路径（在 `mcp-Vulkan` 目录里执行 `pwd`）：

[source,yaml]
----
extensions:
  vulkan:
    type: stdio
    cmd: node
    args:
      - /path/to/mcp-Vulkan/vulkan/build/index.js
----

重启 Goose 会话（`goose session`），然后问它「列出你可用的工具」来确认连接——你应该能看到 `search-vulkan-docs` 和 `get-vulkan-topic`。

=== 把 mcp-Vulkan 接到你的 IDE

同一个服务器也可以直接注册在 IDE 里，替代 Goose（或与它并存）。**JetBrains CLion** 和 **Android Studio** 用户通过 AI Assistant 的 MCP Servers 面板添加；**Visual Studio** 和 **VS Code** 用户可以通过 **Continue** 或 **Copilot** 扩展注册。具体步骤见本节前面各平台的章节。

== 取舍

**文件系统访问是实打实的权限授予，不是走个形式。** 第一次启用带文件系统访问的 MCP 工具时，你的 IDE 或代理会问允许哪个目录。把它限定在项目文件夹——不要把权限给到主目录或项目之外的任何地方。

**它有用的地方：与现有代码保持一致。** 因为模型可以通过 MCP 引入你引擎自身的历史，你可以让它设计一个比如新的后处理通道，要求「风格和内存管理与现有阴影通道一致」。它会真的去读阴影通道的实现，而不是生成一段通用代码——结果仍然需要审阅，但它是从你代码库的约定出发，而不是从一个默认模板出发。

== 小结

MCP 让模型从「凭记忆作答」变成「能拿当前规范和你的代码库核对答案」。这是本节所讲环境搭建的最后一块。
