在接下来的几章中，我们将搭建一个图形管线，用于绘制我们的第一个三角形。图形管线是指将网格的顶点和纹理处理成渲染目标中像素的一系列操作。下面是一个简化的概述：
image:../../../images/图形管线基础知识概述.png[]
输入组装器从您指定的缓冲区收集原始顶点数据，并且还可以使用索引缓冲区来重复某些元素，而无需复制顶点数据本身。

顶点着色器针对每个顶点运行，通常会应用变换将顶点位置从模型空间转换到屏幕空间。它还会将每个顶点的数据传递到渲染管线的下游。

细分着色器允许您根据特定规则细分几何体，从而提高网格质量。这通常用于使砖墙和楼梯等表面在近距离观察时看起来不那么平坦。

几何着色器会对每个图元（三角形、线段、点）进行处理，它可以丢弃图元，也可以输出比输入更多的图元。这类似于细分着色器，但更加灵活。然而，由于除了英特尔集成显卡之外，大多数显卡的性能都不尽如人意，因此几何着色器在当今的应用程序中很少使用。此外，几乎所有几何着色器的应用场景都可以通过更现代的网格着色器管线来解决。网格着色器管线与光线追踪一样，是一种全新的管线解决方案，因此它独立于标准图形管线之外。我们将在后续的教程章节中讨论该管线。

光栅化阶段将图元分割成片段。这些片段是它们填充到帧缓冲区中的像素元素。任何超出屏幕范围的片段都会被丢弃，顶点着色器输出的属性会在这些片段之间进行插值，如图所示。通常，由于深度检测的原因，位于其他图元片段后面的片段也会被丢弃。

片段着色器会针对每个幸存的片段进行调用，并决定将这些片段写入哪个（哪些）帧缓冲区，以及使用哪些颜色和深度值。它可以利用顶点着色器插值的数据来实现这一点，这些数据可以包括纹理坐标和用于光照的法线等信息。

颜色混合阶段会对映射到帧缓冲区中同一像素的不同片段进行混合操作。片段可以简单地相互覆盖、叠加，或者根据透明度进行混合。

绿色的阶段被称为固定功能阶段。这些阶段允许您使用参数调整其操作，但它们的工作方式是预先定义的。

另一方面，橙色阶段是可编程的，这表示您可以将自己的代码上传到显卡，以应用您想要的精确操作。例如，这允许您使用片段着色器来实现从纹理和光照到光线追踪的各种功能。这些程序可以同时在多个 GPU 核心上运行，并行处理大量对象，例如顶点和片段。

如果您之前使用过 OpenGL 和 Direct3D 等旧版 API，那么您应该习惯于使用类似 `glBlendFunc` 和 `OMSetBlendState` 这样的调用随意更改任演示队列何管线设置。Vulkan 中的图形管线几乎完全不可变，因此如果您想更改着色器、绑定不同的帧缓冲区或更改混合函数，则必须从头开始重新创建管线。缺点是您需要创建多个管线来表示渲染操作中要使用的所有不同状态组合。但是，由于管线中所有操作都是预先已知的，因此驱动程序可以对其进行更好的优化。

某些可编程阶段是可选的，具体取决于您的需求。例如，如果您只是绘制简单的几何图形，则可以禁用细分和几何着色器阶段。如果您只关心深度值，可以禁用片段着色器阶段，该阶段对于生成 https://en.wikipedia.org/wiki/Shadow_mapping[阴影贴图]非常有用 。
