= 高级 Vulkan 计算：结语

恭喜你完成「高级 Vulkan 计算」教程系列！你从计算着色器的基本概念一路走到了 Vulkan 1.4 中高性能 GPGPU 开发的前沿。

== 我们学到了什么

在本系列中，我们深入探索了现代 GPU 计算的底层，从简单的图像处理迈进到复杂的异构系统：

1. **计算架构**：我们掌握了工作组网格与物理硬件（CU 与 SM）之间的映射，并学会了如何最大化占用率、隐藏延迟。我们还利用 Vulkan 1.4 的标量布局来获得最高的带宽效率。
2. **内存模型**：我们揭开了 Vulkan 内存模型的面纱，掌握可用性、可见性与域操作，在不牺牲性能的前提下保证线程安全。
3. **子组的力量**：我们用子组洗牌、广播和算术运算以硬件速度交换数据，完全绕过 VRAM 和共享内存（LDS）。
4. **异构生态**：我们探索了如何用 `clspv` 和 `clvk` 把遗留 OpenCL 代码桥接到 Vulkan，后者提供了在 Vulkan 之上分层的合规 OpenCL 3.0——对应用完全透明。
5. **高级数据结构**：我们实现了驻留 GPU 的树、无锁链表，并利用原始的缓冲区设备地址（BDA）获得类指针的灵活性。
6. **GPU 驱动管线**：我们通过间接派发和自主命令生成，把控制权从 CPU 交给 GPU。
7. **异步编排**：我们借助 Synchronization 2 和时间线信号量，发挥多个硬件引擎的能力，让计算与图形并发运行。
8. **专用数学**：我们利用了协作矩阵和混合精度（FP16/Int8）这类现代硬件特性，获得巨大的吞吐量。
9. **性能与诊断**：我们学会了审计内核的分支发散、用 Roofline 模型分析吞吐量，并用 GPU 辅助验证（GAV）调试复杂的竞态条件。
10. **AI 辅助优化**：我们看到了大语言模型（LLM）如何充当桥梁，把朴素、串行的逻辑与 GPU 高吞吐所需的并行、子组感知模式连接起来。
11. **移动与嵌入式计算**：我们把这些技术带到了部署量最大的 Vulkan 硬件上——Android 手机、单板计算机、汽车和机器人——为功耗与带宽做优化，利用统一内存，并在没有显示器的设备上无头运行。

== 让一切融会贯通：计算思维

如果说本系列只有一条要旨，那就是：**GPU 不只是一个数学协处理器；它是一台拥有自身复杂层级的并行吞吐机器。**

为高级计算做开发需要一次思维转变：

- **以波为单位思考**：始终寻找用子组（波）操作替代工作组级屏障的机会。
- **显式同步**：不要靠运气。用 Vulkan 内存模型和 Synchronization 2 精确规定数据何时、以何种方式变得可见。
- **数据优先的设计**：在写下第一行逻辑之前，先按 GPU 的内存架构（标量布局、LDS bank 对齐）设计你的数据结构。

== 接下来往哪里走

高性能计算的世界极其广阔。既然你已经有了扎实的基础，可以考虑这些方向：

1. **深入机器学习**：用你学到的协作矩阵和混合精度知识，优化神经网络推理或训练。
2. **实时光线追踪**：结合 GPU 驱动管线和异步计算，构建一个完全在设备上处理复杂空间结构的高性能光线追踪器。
3. **物理模拟**：用我们讨论过的无锁数据结构实现高级流体动力学（SPH）或刚体求解器。
4. **Vulkan 生态**：为 `clspv` 或 `clvk` 这类项目做贡献，或者在本系列讲过的 Vulkan 特性之上构建你自己的高层计算抽象。

== 社区与资源

和往常一样，你在这段旅程中并不孤单。Vulkan 社区里满是专家和爱好者：

- **Khronos Slack/Discord**：适合针对特定扩展做技术深挖。
- **Vulkan 规范**：关于内存模型和硬件约束的最终权威。
- **厂商专属文档**：想了解桌面硬件专属的优化技巧，可以看 NVIDIA 的 Nsight、AMD 的 RGP 和 Intel 的 GPA 文档。对于移动和嵌入式目标，请查阅 Arm 的 Mali/Immortalis 最佳实践指南和 Performance Studio、Qualcomm 的 Adreno 开发者文档和 Snapdragon Profiler，以及 Imagination 的 PowerVR 开发者资源。

感谢你一路跟随本系列。我们已经从「把像素画得好看」走到了驾驭现代硬件的全部并行能力。现在唯一的限制就是你的想象力。
