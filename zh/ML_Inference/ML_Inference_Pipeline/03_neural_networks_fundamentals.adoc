= 神经网络基础

== 引言

在讨论推理之前，我们先扎实地理解一下神经网络到底是什么。尽管围绕神经网络和 AI 有着巨大的热情，但重要的是理解其基础，而不是把它们当作神奇的黑箱。神经网络很强大，但归根结底它们只是数学函数——受数学规则的限制，也受数学规则的赋能。

本章从第一性原理出发构建对神经网络的理解：从数学函数开始，从生物神经元中汲取灵感，并说明为什么非线性激活函数对神经网络的工作至关重要。

== 什么是函数？

我们从最基本的概念开始：数学函数。*函数*是一种把输入与输出关联起来的方式。数学中所有函数都接受一定数量的输入，并产生唯一一个与这些输入对应的输出。函数的一个关键特性是：给定相同的输入，它们总是产生相同的输出。

注意输出不一定只是一个数——它也可以是一个像向量或矩阵这样的结构。这个简单的概念强大得令人惊讶。事实上，计算机程序本质上就是在运行数学函数，这正是它们能做如此多不同事情的原因。

函数可以根据我们的需要变得任意简单或复杂：

- *线性*：`y = f(x) = x + 1`
- *抛物线*：`y = f(x) = x² + 1`
- *多输入*：`y = f(a,b,c,d) = 23a + 42b + 51c + d`
- *复杂*：线性回归中的梯度下降
- *未知*：`Diagnosis = f(symptoms) = ???`

最后一个例子至关重要：有时我们要找的函数连怎么写都不知道。如果存在一个能把病人的症状与诊断关联起来的函数，而我们不知道这个函数是什么，那么机器学习——尤其是神经网络——可以帮助我们找到它。

正如我们在线性回归中讨论过的，机器学习寻找的是最能拟合数据的函数。神经网络是我们用来寻找未知函数的最通用的工具之一。不过，非常通用也意味着：虽然它们会找到一个函数，但它可能不是最高效的实现。这一点稍后再谈。

== 向自然学习：生物神经元

让我们从人脑的工作方式中汲取灵感。你曾经有过的每一个念头、形成的每一段记忆、学会的每一项技能——所有这些都源自数十亿个神经元协同活动。不可思议的是，每一个单独的神经元都简单得惊人。大脑的复杂性与力量并不来自精巧的单个组件，而是来自大量简单组件协同工作。

=== 结构：通信网络

花一点时间想想你自己的神经系统。当你碰到热的东西时，你会立刻把手缩回来。当你看到朋友的脸时，你会马上认出对方。当你读到这些文字时，你会理解它们的含义。所有这些过程——感觉、识别、理解——都通过相互通信的神经元网络发生。

image::images/ML_Inference/ML_Inference_Pipeline/biological_neuron.png[一个生物神经元，展示了树突、胞体和轴突]

生物神经元有三个主要部分：

1. *树突*——像蜘蛛网一样的结构，从其他神经元接收输入。可以把它们看作神经元的“耳朵”——它们在倾听其他神经元在说什么。单个神经元可能拥有数千个树突，每个树突都连接到不同的神经元，使它能够同时整合来自许多来源的信息。

2. *胞体*（Soma）——神经元的主体部分，处理输入并决定是否激活。这里是“思考”发生的地方——胞体把所有经树突传入的信号加起来，判断合并后的输入是否足够强，值得把消息继续传下去。

3. *轴突*——从胞体延伸出来的长管（起始于轴突丘，终止于轴突末梢），负责传递输出信号。这是神经元的“声音”——当它决定发放时，电信号会沿着轴突飞速传下去，与其他神经元通信。有些轴突长得惊人；控制你脚趾的神经元，其轴突从脊髓一直延伸到你的腿部。

*突触*是一个神经元的轴突末梢与另一个神经元的树突之间的间隙。信号就在这里从一个神经元传递到下一个神经元。有趣的是，神经元实际上并不相互接触——突触处有一个微小的间隙。当电信号到达轴突末端时，会触发化学信使（神经递质）的释放，它们漂浮过这个间隙并结合到下一个神经元树突上的受体。这种化学通信对大脑的运作至关重要。

注意这个关键模式：每个神经元有许多树突（多个输入）和一根轴突（单个输出）。听起来很熟悉？这正是我们之前讨论的数学函数的定义！这不是巧合——当我们设计人工神经网络时，正是直接受到这种生物结构的启发。

=== 神经元的实际工作方式：发放过程

生物过程优雅而简单，却十分强大。想象你在听音乐会，正犹豫要不要开始鼓掌。你在听周围的人——有些人在热情鼓掌，有些人安静坐着，还有人在喝倒彩。你下意识地权衡着所有这些输入：“我附近有三个人在鼓掌，但有两个人没动静，还有一个人特别热情……” 当你收到的信号中有足够多都在说“鼓掌”时，你也开始鼓掌。

神经元的工作方式类似。胞体通过多个树突接收信号。其中一些信号是*兴奋性*的——它们推动神经元发放。另一些是*抑制性*的——它们阻碍发放。胞体不断地对这些相互竞争的信号求和。当总兴奋超过某个阈值时，神经元就沿着轴突发送一个电脉冲，也就是“发放”。

发放是全有或全无的事件。神经元不会“稍微”发放或“大量”发放——它要么发放，要么不发放，就像拨动电灯开关一样。不过，神经元可以以不同的频率反复发放。一个接收到强烈而持续兴奋的神经元，可能每秒发放很多次；而一个接收较弱信号的神经元，可能只是偶尔发放。神经元正是用发放频率来编码信号的强度。

真正有趣的地方在于：发放阈值并不是固定的。通过一个称为*突触可塑性*的过程，神经元之间的连接会随时间增强或减弱。当你学到新东西时，你实际上是在改变大脑中突触连接的强度。“一起发放的神经元会连在一起”这句话概括了这个想法——当两个神经元反复同时活跃时，它们之间的连接就会增强，使其中一个以后更容易激活另一个。

=== 网络的力量：复杂性如何涌现

单个神经元很简单，但你的大脑包含大约 860 亿个神经元，每个都连接到数千个其他神经元。那就是数万亿的连接，形成复杂得令人震惊的网络。神奇之处就在这里发生。

想想你认出一张脸时会发生什么。光线落在你的视网膜上，激活你眼睛里的神经元。这些神经元把信号发送到视觉皮层中的神经元，后者检测边缘和颜色等基本特征。那些神经元又连接到识别曲线和形状等更复杂模式的神经元。再往后连接到识别眼睛和鼻子等面部特征的神经元。最后连接到识别具体面孔的神经元——你的大脑中确实有专门对熟悉面孔做出反应的神经元。

这是一个*特征层级*。简单的神经元检测简单的东西。它们的输出馈入检测更复杂东西的神经元。如此层层递进，从基本的感官输入一路构建到高层概念。这种层级化的组织方式，是我们在构建人工神经网络时会用到的关键洞见之一。

记忆也遵循类似的原理。当你回忆起某件事时，你并不是在访问存储在某个特定位置的文件（像计算机那样）。相反，你是在重新激活一种神经活动模式。关于童年故居的记忆涉及编码视觉细节、情感联想、空间关系等的神经元——它们全都在以一种协调的模式一起发放。这就是为什么记忆会被意想不到的线索触发：一种气味、一首歌、一个看起来相似的地方。模式的任何一部分都能重新激活整体。

=== 可塑性与学习：大脑的超能力

生物神经网络也许最了不起的特性，是它们能够重组自身。这被称为*神经可塑性*，是一切学习的基础。

当你练习一项技能——演奏乐器、说一门语言、解数学题——你是在强化特定的神经通路。参与这项技能的神经元反复一起发放，它们的连接变得更强。这就是练习有效的原因：你实际上是在重新布线你的大脑，让它更高效地完成那项任务。

大脑对损伤的适应能力也非同寻常。如果某个区域受损，其他区域有时能接管它的功能。失去视力的人往往会发展出更强的听力和触觉——这并不是因为他们的耳朵或手指变了，而是因为原本处理视觉的大脑区域被改用来处理其他感官。神经元还是那些神经元；改变的是连接和模式。

这种适应性也延伸到专门化。虽然某些大脑区域倾向于处理某些任务（对大多数人来说语言在左半球，空间推理在右半球），但这些并不是硬编码的。大脑根据经验来组织自己。职业音乐家的大脑分配给音乐处理的神经“地盘”比非音乐家更多。伦敦出租车司机的大脑因为要记住这座城市复杂的街道布局，海马体（参与空间导航的区域）会变大。

=== 为什么这对人工神经网络很重要

理解生物神经元既给了我们灵感，也给了我们谦逊。

灵感是显而易见的：大脑的结构——简单的处理单元、带权重的连接、层级化组织、通过调整连接强度来学习——为人工神经网络提供了蓝图。

谦逊则来自认识到我们省略了什么。生物神经元远比我们的人工版本复杂。它们有复杂的内部化学过程，通过几十种不同的神经递质通信，形成的连接可以是兴奋性的或抑制性的，还同时在多个时间尺度上运作。我们并不试图复制所有这些复杂性——我们提取核心的计算原理，并用一种可以在数学上处理的形式来实现它们。

关键洞见是：你不需要完美地模拟生物学，也能获得它的计算能力。正如飞机不像鸟那样扇动翅膀，却依然能飞行，人工神经网络也不复制生物神经元的每个细节，却依然能实现令人印象深刻的信息处理能力。

我们构建的东西受生物学启发，但针对在数字计算机上的实现做了优化——具体来说，是针对使用 Vulkan 计算着色器在 GPU 上的高效执行。我们取来核心思想（加权输入、阈值、由简单单元组成的网络、通过调整来学习），并以一种能很好地映射到并行计算的形式实现它们。

== 模仿自然：人工神经元

有了这些生物学理解，我们就可以通过创建人工神经元来复制大脑的工作方式：这些神经元接收输入、做出决策并产生输出。一个有三个输入和一个输出的人工神经元看起来是这样的：

image::images/ML_Inference/ML_Inference_Pipeline/linear_perceptron.png[一个有三个输入和一个输出的人工神经元（感知机）]

这意味着我们的人工神经元有一个数学函数：`output = f(x, y, z)`。

但我们应该用哪个函数呢？在回答这个问题之前，我们需要理解两个让神经网络得以工作的基本概念：*权重*和*偏置*。

=== 理解权重：重要性的乘数

*权重*是一个与输入相乘的数，决定该输入对输出的影响有多大。大的权重意味着“这个输入很重要”。小的权重意味着“这个输入几乎不重要”。负权重意味着“这个输入把输出往相反方向推”。

做决策时，我们自然会以不同的方式权衡不同因素——有些因素比其他因素更重要。神经网络在数学上做的也是同样的事。

在我们的三输入神经元中，可能有：

- `w₁ = 5.0`（第一个输入非常重要）
- `w₂ = 0.1`（第二个输入几乎不重要）
- `w₃ = -2.0`（第三个输入中等重要，但方向相反）

当神经元计算 `w₁·x + w₂·y + w₃·z` 时，它是在创建一个加权和——每个输入按其权重成比例地贡献结果。这就是神经元“学习”哪些输入重要的方式：在训练期间，这些权重会被不断调整，直到神经元对其输入做出正确的反应。

=== 理解偏置：阈值的调节器

*偏置*是一个加到加权和上的常量，用来调节神经元的激活阈值。大的正偏置让神经元更容易激活（它更乐意发放）。大的负偏置让它更难激活（需要更强的输入信号才能发放）。

偏置代表神经元的“默认倾向”。在完全没有输入的情况下（x = 0，y = 0，z = 0），加权和会是零。但如果偏置是比如 `b = -10`，神经元就从 -10 开始，需要正的输入来克服这个负偏移。如果偏置是 `b = +10`，神经元已经倾向于激活了。

权重和偏置一起赋予每个神经元独特的个性——它对什么做出反应，以及多么容易发放。在训练期间，权重和偏置都会被调整，使网络产生正确的输出。在推理期间（我们关注的重点），它们是固定值，我们从训练好的模型中加载它们并在计算中使用。

=== 组合起来：线性神经元

现在我们可以更有意义地写出神经元的函数了。我们从一个实验开始。假设函数是线性的——也就是说，它描述的是一条直线或一个平面：

[source]
----
output = f(x, y, z) = w₁·x + w₂·y + w₃·z + b
----

其中：

- `w₁`、`w₂`、`w₃` 是*权重*（决定每个输入重要性的学习得到的值）
- `b` 是*偏置*（调节激活阈值的学习得到的值）
- `x`、`y`、`z` 是输入
- 输出就是加权和加上偏置

== 线性函数的问题

现在我们来看看把多个神经元连接成网络会发生什么：

image::images/ML_Inference/ML_Inference_Pipeline/neural_network_example.png[一个简单的神经网络，包含输入层、隐藏层和输出层]

在这个网络中，输出来自节点 N6。我们顺着数学推一遍：

*最终层：*

[source]
----
output = N6_output
N6_output = w_a · N5_output + w_b · N4_output + w_c · N3_output + b_d
----

*隐藏层：*

[source]
----
N3_output = w_e · N1_output + w_f · N2_output + b_g
N4_output = w_h · N1_output + w_i · N2_output + b_j
N5_output = w_k · N1_output + w_l · N2_output + b_m
----

*输入层：*

[source]
----
N1_output = w_n · X + w_o · Y + w_p · Z + b_q
N2_output = w_r · X + w_s · Y + w_t · Z + b_u
----

问题就在这里：如果我们把这些方程相互代入并化简，会得到：

[source]
----
output = f(x,y,z) = w_final_a · X + w_final_b · Y + w_final_c · Z + b_final
----

我们整个神经网络坍缩成了一个线性函数！这是因为*线性函数的组合永远是线性的*，无论我们加多少层。所有多出来的神经元只是制造了不必要的计算，而这些计算本可以化简为更简单的形式。我们在描述数万亿种可能的生物连接时谈到的美妙复杂性，在数学的简单性面前消失了。用线性激活函数设计出的网络，根本无法保持复杂性。

== 解决方案：非线性激活函数

为了解决这个问题、把复杂性找回来，我们需要使用*非线性函数*——输入和输出之间不具有线性关系的函数。这给了我们一个令人惊讶而强大的性质：根据*通用近似定理*，任何函数都可以由非线性函数组成的神经网络来近似。

想一想：如果存在某个函数能把一些输入与一些输出关联起来，那么使用非线性函数的神经网络就能近似那个函数。我们只需要输入和输出，就能近似那个函数。这正是神经网络如此强大、如此通用的原因。

虽然非线性函数有很多，但我们来讨论一个对我们的目的来说最直观的：*sigmoid 函数*（也叫逻辑函数）：

[source]
----
σ(z) = 1 / (1 + e^(-z))
----

sigmoid 函数有几个有用的性质：

- 它的输出总是在 0 和 1 之间（表示从“关”到“开”）
- 它平滑且可微（这对训练很重要，虽然对推理不重要）
- 它天然产生阈值行为

当 sigmoid 的输出大于 0.5 时，我们可以认为神经元“被激活”了。我们甚至可以引入偏置，或者想办法调整这个 0.5 的激活阈值。我们可以在应用激活函数之前加上一个偏置项来做到这一点。

== 具体示例：构建 AND 门

我们用一个简单的例子看看这是如何工作的。我们要构建一个实现逻辑 AND 函数的神经网络：

image::images/ML_Inference/ML_Inference_Pipeline/basic_and_node.png[一个用 sigmoid 激活实现 AND 门的单个神经元]

这个神经元计算：`output = σ(-30 + 20·X + 20·Y)`

我们来推一遍真值表：

[cols="1,1,2,1", options="header"]
|===
|X |Y |计算 |输出

|0
|0
|σ(-30 + 0 + 0) = σ(-30)
|≈ 0

|1
|0
|σ(-30 + 20 + 0) = σ(-10)
|≈ 0

|0
|1
|σ(-30 + 0 + 20) = σ(-10)
|≈ 0

|1
|1
|σ(-30 + 20 + 20) = σ(10)
|≈ 1
|===

我们的单层神经网络成功实现了 AND 函数！权重（20、20）和偏置（-30）被选中，以产生正确的阈值行为。

== 通用性的代价

这个例子揭示了一个重要洞见：如果你已经知道要找的函数（比如 AND），那么神经网络就大材小用了。一个简单的 AND 运算是单个常量时间的操作。但在神经网络中，我们必须：

1. 存储学习得到的权重和偏置（-30、20、20）
2. 执行浮点乘法和加法
3. 计算 sigmoid 函数（涉及指数运算）
4. 每次预测都要做所有这些事

与直接实现相比，这*非常昂贵*。神经网络之所以强大，是因为它们能找出未知的函数，但它们并不是实现已知函数的最有效方式。

当你事先知道输入与输出之间的关系时，就用比神经网络更简单的东西。然而，当你需要从数据中发现函数时——而更简单的机器学习方法（如线性回归、支持向量机等）又失败了——神经网络最终可以通过训练找到正确的函数。

== 现代激活函数：为什么 sigmoid 不够

我们一直聚焦于 sigmoid 函数，因为它性质直观——它能把任意输入平滑地映射到 0 和 1 之间的值，模拟生物神经元的“开/关”行为——但现代神经网络很少在隐藏层中使用 sigmoid。为什么呢？要理解这一点，我们需要短暂地窥视一下训练过程，并理解一些关于神经网络如何学习的基本概念。

=== 神经网络如何学习：温和的入门

在讨论 sigmoid 的局限之前，我们先理解神经网络实际上如何学习。请记住，本教程关注的是推理，但理解训练的基础有助于我们领会为什么模型使用不同的激活函数，以及如何正确实现它们。

回想我们的 AND 门例子。我们说权重被“选中”为 20、20 和 -30。但神经网络如何自己发现这些值呢？这就是训练的用武之地。

==== 学习问题

神经网络训练是一个迭代过程。网络做出预测，我们衡量它错了多少（*误差*或*损失*），然后调整权重来减小这个误差。关键问题是：我们*如何*调整权重？如果增大某个权重，误差会上升还是下降？上升或下降多少？

==== 梯度登场

这就是*梯度*登场的地方。梯度简单来说就是衡量当你改变输入时输出变化多少的量度。用微积分的术语说，它就是导数——函数在某一点的斜率。

我们把这个具体化。假设你有一个简单的函数：`error = (prediction - actual)²`。如果你的预测是 0.8，实际值是 1.0，那么你的误差是 `(0.8 - 1.0)² = 0.04`。现在，如果你把预测稍微增大到 0.81，误差变成 `(0.81 - 1.0)² = 0.0361`。误差下降了！梯度告诉你这种关系：“如果你增大预测值，误差会减小。”

对神经网络来说，我们需要知道：如果我们改变某个权重，误差会如何变化？误差关于该权重的梯度正好告诉我们这一点。如果梯度为正，增大权重会增大误差（不好）。如果梯度为负，增大权重会减小误差（好）。

==== 梯度下降：山间小路的类比

一旦我们知道每个权重的梯度，就可以使用一个简单而优美的算法：*梯度下降*。为了理解它如何工作，我们建立一个详细的心智模型。

===== 从随机猜测开始

想象你被随机丢在一条山间小路的某处——也许靠近山顶，也许在半山腰，也许在一条山脊上。你没有地图，没有 GPS，只有双脚，以及感受哪个方向向下倾斜的能力。你的目标是到达下方山谷中的最低点。

神经网络训练正是这样开始的。我们从*随机初始权重*开始——本质上是对函数应该是什么的随机猜测。这些初始权重可能很糟糕，产生的预测错得离谱。没关系；我们并不指望一开始就有好的权重。我们是指望通过训练过程*找到*好的权重。

===== 损失函数：你的指南针

你如何知道自己在取得进展？你需要一种方法来衡量你当前位置错得有多离谱。在我们的登山类比中，这就是你的海拔——你越高，离目标越远。

在神经网络中，这种衡量被称为*损失函数*（也叫*误差函数*或*代价函数*——这些术语可以互换使用）。损失函数接收模型的预测，把它们与实际的正确答案比较，产生一个代表你“错得有多离谱”的单一数字。

常见的损失函数包括：

*均方误差（MSE）*：`loss = average((prediction - actual)²)`——用于回归问题，即你预测的是连续值。对误差取平方意味着大错误比小错误受到更重的惩罚。

*交叉熵损失*：用于分类问题，即你预测的是类别。它衡量你预测的概率分布与真实分布相差多远。

关键洞见：损失函数创造了一个地形。每一种可能的权重组合都对应这个地形中的一个点，该点的“高度”就是损失。好的权重在山谷里（低损失），坏的权重在山峰上（高损失）。训练就是在这个地形中导航、寻找山谷的过程。

===== 向下迈步

回到我们的山间小路。你感受脚下的地面，判断哪个方向向下倾斜得最陡。你朝那个方向迈一步。然后在落脚处再次感受坡度，再迈一步。你重复这个过程，始终朝下坡的方向移动。

这就是梯度下降。梯度告诉你权重空间中哪个方向是“下坡”——哪个方向最快地减小损失。你朝那个方向调整权重：

[source]
----
new_weight = old_weight - learning_rate × gradient
----

负号至关重要：如果梯度为正（权重增大时损失增大），我们就*减小*权重。如果梯度为负（权重增大时损失减小），我们就*增大*权重。我们始终逆着梯度移动，也就是向下坡移动。

`learning_rate` 是你迈步的大小。这是一个关键参数：

- *太大*：你可能直接跃过山谷，从一侧弹到另一侧，永远无法停在山谷底部。更糟的是，你可能跳到山上完全不同的区域。
- *太小*：你最终会到达底部，但可能需要数千甚至数百万步。训练会变得极其缓慢。
- *刚刚好*：你稳步向最小值前进，而不会冲过头。

在实践中，学习率通常开始时较大（以便快速取得进展），然后逐渐减小（以便稳定进入最小值而不冲过头）。这被称为*学习率调度*。

===== 何时停止：收敛

你如何知道已经到达底部？在我们的登山类比中，你可能会注意到无论朝哪个方向迈步，都是上坡。你处在局部低点。

在神经网络训练中，我们寻找*收敛*——损失不再显著下降的那个点。有几个指标告诉我们已经收敛：

*损失进入平台期*：损失值在训练步骤之间几乎不再变化。如果损失先是 0.523，然后 0.522，然后 0.521，并且已经有很多步变化都小于 0.001，那么你很可能已经收敛了。

*梯度幅值变得极小*：当梯度趋近于零时，你处在地形中的平坦处——要么是最小值，要么是平台。

*验证性能停止提升*：这是最实用的指标。你留出一部分模型在训练中没见过的数据（验证集），定期检查它上面的性能。当验证性能停止提升时，就该停止训练了。

===== 挑战：局部极小值与全局极小值

这里我们的登山类比揭示了一个关键挑战。想象地形不是简单的碗状山谷，而是一片复杂的山脉，有许多山谷、山脊和洼地。有些山谷很深（低损失），另一些很浅（较高的损失）。

如果你从山上的某个地方出发，沿梯度下坡，你可能会最终落入一个小洼地——一个*局部极小值*。在那里，每个方向都是上坡，于是梯度下降就停下了。但山脊的另一侧可能有一个深得多的山谷（*全局极小值*）。你永远找不到它，因为必须先上坡翻过山脊才行。

这是神经网络训练中的一个根本挑战：

*全局极小值*：整个损失地形中的绝对最低点。它代表你的模型在训练数据上可能达到的最佳权重。

*局部极小值*：一个被更高点包围的低点，但不是绝对最低点。梯度下降可能卡在这里。

在实践中，对于现代深度神经网络，这个问题并没有你想象的那么严重。高维空间（数百万个权重）中的损失地形具有有趣的性质——存在许多“足够好”的极小值，它们表现都差不多好。找到绝对的全局极小值并不必要；找到任何一个足够深的极小值就能很好地工作。

此外，像下面这些技术：

- *动量*：给梯度下降加上“惯性”，让它能滚过小凸起和洼地
- *随机重启*：从不同的随机初始化多次开始训练
- *随机梯度下降*：在训练过程中引入随机性，这有助于逃离浅的局部极小值

能帮助在复杂的损失地形中导航，即使全局极小值难以企及，也能找到好的解。

===== 评估模型：如何判断模型更好

了解了训练如何工作的基础之后，一个重要问题出现了：我们怎么知道自己的模型是否真的不错？我们如何比较两个不同的模型并决定哪个更好？

损失函数告诉我们模型对训练数据的拟合程度，但这不是全部。我们真正关心的是模型在*新的、未见过的数据*上表现如何——那些它没有训练过的数据。这被称为*泛化*。我们简要谈谈学习过程，以及推理模型是如何形成的。

====== 训练、验证与测试数据

为了正确评估模型，我们把数据分成三个集合：

*训练数据*（通常占数据的 70-80%）：用于训练模型——通过梯度下降调整权重。模型在训练期间看到这些数据并从中学习。

*验证数据*（通常占数据的 10-15%）：用于在训练期间评估模型并调整超参数（如学习率、网络架构等）。模型不在这些数据上训练，但我们用它来对训练过程做决策。

*测试数据*（通常占数据的 10-15%）：只在最后阶段使用，以获得模型性能的最终、无偏估计。模型在训练或超参数调整期间从不接触这些数据。

为什么需要三个集合？如果我们只有训练数据，就无法分辨模型是在死记训练样本（过拟合），还是真的在学习通用模式。如果我们只有训练数据和测试数据，我们就会忍不住根据测试性能来调模型，这会把测试集的信息泄漏到模型设计中。三路划分让我们的最终评估保持诚实。

====== 关键评估指标

不同的任务需要不同的指标：

*用于分类（预测类别）*：

- *准确率*：预测正确的百分比是多少？简单直观，但如果类别不平衡，可能会有误导（例如，如果 95% 的样本是“非垃圾邮件”，一个总是预测“非垃圾邮件”的模型准确率是 95%，但毫无用处）。

- *精确率与召回率*：精确率问的是“在我们预测为正的样本中，有多少实际上为正？”召回率问的是“在所有实际为正的样本中，我们找出了多少？”这些对不平衡问题至关重要。

- *F1 分数*：精确率和召回率的调和平均，提供一个兼顾两者的单一数字。

*用于回归（预测连续值）*：

- *平均绝对误差（MAE）*：预测值与实际值之间绝对差值的平均。容易解释——如果 MAE 是 5，说明预测平均偏差 5 个单位。

- *均方误差（MSE）*：差值平方的平均。对大误差的惩罚比小误差更重。

- *R² 分数*：衡量模型解释了数据中多大比例的方差。R² 为 1.0 意味着完美预测，0.0 意味着模型并不比直接预测平均值更好。

====== 比较模型

比较两个模型时，我们看它们在验证集（开发期间）或测试集（最终评估）上的表现：

*模型 A 的验证损失低于模型 B*：在假设两个模型复杂度相近的情况下，模型 A 很可能更好。损失更低意味着对数据拟合得更好。

*模型 A 的验证准确率高于模型 B*：对于分类任务，模型 A 做出了更多正确的预测。

*模型 A 的验证误差更低，但训练误差高于模型 B*：这可能说明模型 A 泛化得更好——它不像模型 B 那样过拟合训练数据。

关键洞见：好的模型不只是训练数据上表现好的模型——而是在它未见过的数据上表现好的模型。这就是为什么我们总是在留出的验证集/测试集上评估，而从不只依赖训练数据。

====== 过拟合与欠拟合

两种常见的失败模式帮助我们理解模型质量：

*过拟合*：模型在训练数据上表现很好，但在验证数据上表现很差。它本质上记住了训练样本，而不是学习通用模式。当模型相对于可用的训练数据量来说过于复杂时，就会发生这种情况。解决办法包括：获取更多训练数据、使用更简单的模型，或应用正则化技术。

*欠拟合*：模型在训练数据和验证数据上都表现很差。它根本没有学到数据中的模式——模型太简单，无法捕捉底层关系。解决办法包括：使用更复杂的模型、训练更长时间，或改进特征/数据表示。

理想状态是模型在训练数据和验证数据上都表现良好，且验证性能接近（但通常略低于）训练性能。这说明模型学到了能迁移到新数据的通用模式。

==== 反向传播：高效计算梯度

这里有一个挑战：一个神经网络可能有数百万个权重。我们需要误差关于*每一个权重*的梯度。朴素地计算这些会慢得不可能。

*反向传播*是让这件事变得高效的巧妙算法。它使用一个称为*链式法则*的数学原理，通过一次网络反向遍历计算出所有这些梯度。

==== 理解链式法则

链式法则是微积分中的一个基本概念，它告诉我们当存在*复合函数*——嵌套在其他函数中的函数——时，如何求变化率。

关键原理是：当 A 影响 B，B 影响 C 时，A 对 C 的影响等于各个单独影响相乘。

用数学表达，如果你有 `y = f(u)` 和 `u = g(x)`，那么 y 关于 x 的变化率是：

[source]
----
dy/dx = (dy/du) × (du/dx)
----

你把外层函数的导数乘以内层函数的导数。这可以扩展到更长的链：如果有四个函数嵌套在一起，你就把四个导数乘在一起。

==== 为什么神经网络非常适合链式法则

这里有一个美妙的洞见：*神经网络本质上是复合函数*。每一层都是一个函数，它把上一层的输出作为输入。当你把各层堆叠起来时，你就是在复合函数：

[source]
----
output = layer_n(layer_{n-1}(...layer_2(layer_1(input))...))
----

这正是链式法则为之设计的结构！我们顺着一个简单的例子推一遍。假设我们有一个三层网络：

1. 输入层计算：`h₁ = activation(W₁ × input + b₁)`
2. 隐藏层计算：`h₂ = activation(W₂ × h₁ + b₂)`
3. 输出层计算：`output = activation(W₃ × h₂ + b₃)`
4. 误差被计算：`error = (output - target)²`

现在，如果我们想知道改变第一层中的某个权重（比如 W₁ 中的一个元素）会如何影响最终的误差，就需要沿着这条依赖链追溯：

- 改变 W₁ 影响 h₁
- 改变 h₁ 影响 h₂
- 改变 h₂ 影响 output
- 改变 output 影响 error

根据链式法则，误差关于 W₁ 的梯度是：

[source]
----
∂error/∂W₁ = (∂error/∂output) × (∂output/∂h₂) × (∂h₂/∂h₁) × (∂h₁/∂W₁)
----

我们把所有中间导数乘在一起。这就是它被称为“反向传播”的原因——我们从误差（末端）出发，把梯度逐层向后传播，沿途乘以每一层的导数。

==== 关于激活函数的关键洞见

这里就是激活函数变得关键的地方：每一层的导数都包含其激活函数的导数。当我们计算 `∂h₁/∂W₁` 时，需要该层所用激活函数的导数。

如果激活函数的导数很小（比如输入较大时的 sigmoid），这个小数值就会被乘进链中。在有许多层的深层网络中，你把许多小数乘在一起，梯度就可能消失——变得太小，以至于学习实际上停止了。这就是为什么激活函数的选择对训练如此重要，也是为什么最终出现了像 ReLU 这样具有更好梯度性质的函数。

=== 训练挑战：梯度消失

现在我们就能理解 sigmoid 的问题了。在反向传播期间，穿过每一层向后流动的梯度都会乘以该层激活函数的导数。

sigmoid 的问题在于：对于大的正输入或负输入，它的梯度非常小。当你远离零时（比如在 x = 10 或 x = -10），sigmoid 曲线几乎是平的，因此它的导数趋近于零。在反向传播期间，这些微小的梯度在向后流经网络时被乘在一起。在有许多层的深层网络中，你把许多小数乘在一起，梯度实际上就消失了——变得太小，学习随之停止。

这被称为*梯度消失问题*，它困扰着早期的深度神经网络。靠近输入的层几乎学不到任何东西，因为来自输出的梯度信号到达它们时已经衰减到几乎为零。

=== ReLU 登场：一个简单的解决方案

2011 年，研究者发现一个简单得惊人的激活函数可以在很大程度上解决这个问题：

*ReLU（修正线性单元）*：`f(x) = max(0, x)`

ReLU 简单得几乎令人尴尬：如果输入为正，就原样输出；如果为负，就输出零。然而这种简单带来了几个优势：

1. *正值时没有梯度消失*——对任何正输入，梯度都恰好是 1，因此在反向传播中不会衰减
2. *计算开销低*——只需一次比较和一次选择，没有 sigmoid 那样的指数运算
3. *稀疏激活*——大约一半的神经元输出为零，形成更高效的稀疏表示

ReLU 成为深度网络中隐藏层的默认激活函数，使训练比以往深得多的架构成为可能。这是一个关键突破，助推了深度学习革命。

然而，ReLU 有它自己的问题：*ReLU 死亡问题*。如果一个神经元的输出在训练中变为负值，ReLU 就输出零，梯度也为零。这个神经元完全停止学习，并在余下的训练中一直“死亡”。在某些网络中，相当一部分神经元会这样死去。

=== 变体与替代方案

ReLU 解决了梯度消失问题，但引入了 ReLU 死亡问题。这激发了对激活函数的研究，希望既能保留 ReLU 的优势，又能解决它的局限。但故事并没有到此结束——不同的神经网络架构有不同的需求，研究者发现没有哪一种激活函数对所有情况都是最优的。

==== Leaky ReLU：修复神经元死亡问题

*Leaky ReLU*：`f(x) = max(0.01x, x)`

对 ReLU 死亡最直接的修复很简单：不要让梯度恰好变成零。Leaky ReLU 对负输入不再输出零，而是输出一个小的负值（通常是 0.01x）。这确保神经元永远不会完全死亡——它们总能在训练中恢复，因为梯度永远不是恰好为零。

Leaky ReLU 保留了 ReLU 所有的计算优势（仍然只是一次比较和一次乘法），同时消除了神经元死亡问题。对许多应用来说，它是 ReLU 的直接替代品，效果略好一些。

==== Tanh：当需要对称性时

但是等等——如果 Leaky ReLU 修复了 ReLU 的问题，为什么我们还需要其他激活函数？答案在于理解不同架构有不同的需求。

*Tanh（双曲正切）*：`f(x) = tanh(x)`

Tanh 解决的是另一个问题：ReLU 及其变体的不对称性。ReLU 系列函数总是输出非负值（Leaky ReLU 大部分也是非负的）。这会造成一个微妙的问题：如果一层中所有激活值都是正的，那么下一层权重的梯度就会全都有相同的符号。这会使优化效率降低——网络在权重空间中只能朝某些方向移动。

Tanh 输出的值在 -1 到 1 之间，以零为中心。这种*零中心输出*意味着激活值可以是正的或负的，让梯度能指向任何方向。对某些架构，特别是处理序列的循环神经网络（RNN），这种对称性对稳定训练很重要。

代价是什么？Tanh 仍然受梯度消失困扰，虽然比 sigmoid 轻一些。它的计算比 ReLU 更昂贵（需要指数运算）。所以它不是通用的替代品——只有当它的特定性质（零中心、有界输出、平滑梯度）对架构有益时才会被使用。

==== 其他现代变体：专用解决方案

除了 Leaky ReLU 和 Tanh，研究者还开发了针对特定场景优化的激活函数：

*PReLU（参数化 ReLU）*：类似 Leaky ReLU，但负斜率是在训练中学习得到的，而不是固定的。这增加了灵活性——网络可以决定每一层保留多少负信息。

*ELU（指数线性单元）*：对负输入输出负值（像 Leaky ReLU），但使用平滑的指数曲线而不是线性斜率。这有助于极深网络中的训练稳定性。

*GELU（高斯误差线性单元）*：用于 GPT 和 BERT 等现代 transformer 架构。它基于随机正则化的思想，具有平滑、非单调的性质，似乎有助于训练超大型语言模型。

这些变体中的每一个都源自特定架构中的特定训练挑战。它们不是随意选择的——它们反映了对不同激活性质如何在不同语境中影响学习动态的深刻理解。

=== 为什么这对推理很重要

你可能会想：“如果这些激活函数是为了解决训练问题而设计的，那它们对推理为什么重要？我们又不训练任何东西！”

好问题。理解这些对推理之所以重要，原因如下：

1. *你会在真实模型中遇到这些函数*——当你加载一个预训练模型时，需要实现它所用的任何激活函数。理解它们为什么存在、为什么需要，有助于你正确地实现它们，并且清楚该在何时、对什么进行优化。

2. *性能特征不同*——ReLU 的计算比 sigmoid 快得多（没有指数运算），当你每秒要运行数千次推理时这很重要。了解计算成本有助于你优化 Vulkan 着色器。

3. *数值稳定性*——有些激活函数比另一些更容易出现数值问题（上溢、下溢）。理解它们的行为有助于你写出健壮的推理代码。

4. *架构理解*——不同的模型架构出于合理的原因使用不同的激活函数。一个模型在某些层用 tanh、在另一些层用 ReLU 并非随意——它反映了训练动态以及模型学到的函数。

对我们在 Vulkan 中的实现来说，激活函数的选择会影响我们需要在计算着色器中实现哪些操作。ReLU 很简单（一次 max 操作），而 sigmoid 需要计算指数。实现细节我们会在后面的章节中介绍，但现在你已经理解了模型*为什么*使用不同的激活函数，以及它们代表什么样的权衡。

== 小结

神经网络是数学函数，可以近似任何其他函数，这使它们成为发现数据中未知关系的有力工具。它们从生物神经元中汲取灵感，后者接受多个输入，并根据是否达到阈值产生单个输出。

关键洞见是：仅有线性函数是不够的——无论网络多深，它们都会坍缩成更简单的形式。sigmoid、ReLU 和 tanh 等非线性激活函数，对神经网络近似复杂函数来说必不可少。

虽然神经网络通用而强大，但它们是有代价的：与已知函数的直接实现相比，它们的计算开销很大。这种计算成本正是使用 Vulkan 进行 GPU 加速对实时推理至关重要的原因。

有了对神经网络在根本层面上如何工作的理解，我们就可以去探索训练与推理之间的区别，并理解在 GPU 上运行推理意味着什么。
