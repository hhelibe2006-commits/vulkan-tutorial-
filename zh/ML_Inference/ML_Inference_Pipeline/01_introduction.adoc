= ML 推理管线：简介

[NOTE]
====
本章是一个背景性的「教科书」段落，从第一性原理出发讲解机器学习概念。它的内容非常密集，也力求完整。已经熟悉机器学习的读者可以跳到下一章：xref:ML_Inference/Third_Party_Libraries/01_introduction.adoc[集成第三方 ML 库：简介]。
====

== 简介

你已经学完了 Vulkan 教程。你能创建图形管线、管理内存、派发计算着色器。你知道如何让 GPU 按你的意愿行事。现在你开始关注机器学习，并且想知道：这两者怎么凑到一起？我如何把一个训练好的神经网络真正用 Vulkan 跑在 GPU 上？

这就是本章要讲的内容。不是训练神经网络的数学——那完全是另一回事。我们聚焦于 *推理*：把别人已经训练好的模型拿到你的 GPU 上高效运行。可以这样理解：别人造好并调校好了引擎，把钥匙交到你手里。你的任务是把它开得足够快。

但问题在于：你不能直接跳到为神经网络编写计算着色器。如果你不真正理解神经网络 *是什么*——它执行哪些运算、这些运算为什么重要、数据如何在其中流动——那你就是在盲写代码。你也许能让它跑起来，但不会明白它为什么能工作，也不知道它坏掉时该怎么修。

本章为你打好这个基础。我们会探讨机器学习是什么、神经网络如何从第一性原理出发运作、推理意味着什么，以及如何把神经网络看作 GPU 计算操作。读完之后，你会得到一个清晰的心智模型，把高层的 ML 概念与你将要编写的底层 Vulkan 代码连接起来。

== 本章涵盖的内容

我们将走完一段旅程，从「机器学习是什么？」到「我如何把它映射到 GPU 执行？」。路线如下：

首先，我们讨论 *机器学习到底是什么*。不是炒作，也不是流行词，而是真实的东西。计算机如何从数据中学习模式？这为什么有用？它在真实应用中出现在哪里，尤其是在图形与实时系统里？这些背景很重要，因为它能帮你理解为什么 GPU 加速至关重要，以及在哪些场景下基于 Vulkan 的推理才说得通。

然后我们 *从零开始深入神经网络*。我们从简单的数学函数起步，逐步构建出复杂的网络。你会看到生物神经元如何启发了人工神经元、为什么仅仅线性函数不够用、以及为什么激活函数不可或缺。我们会做具体例子——比如用单个神经元构建一个 AND 门——让你确切理解每一步发生了什么。这不是抽象理论，而是你将要编写的计算着色器的基础。

接下来，我们会澄清 *训练与推理* 之间的关键区别。训练是学习发生的地方——通过梯度下降和反向传播调整数百万个权重。推理则是用这些学到的权重做出预测。我们聚焦于推理，但了解一点训练能让你明白自己在实现什么，以及模型为什么会是现在这样的结构。

我们会探讨 *迁移学习*——一个现实情况：你几乎永远不会从零开始训练模型。相反，你会拿预训练模型来适配自己的需求。理解它如何运作、为什么如此强大，会影响你开展 Vulkan 推理项目的方式。

然后我们处理 *模型格式*：TFLite 和 ONNX。这些是把训练好的模型打包以便部署的文件格式。你需要理解这些文件里有什么、它们有何不同、以及如何在两者之间转换。这些实用知识你在把模型载入 Vulkan 应用时会立刻用到。

最后，我们建立一个 *GPU 执行的心智模型*。神经网络——这个抽象的数学对象——如何映射到缓冲区、计算着色器和管线屏障？你该如何思考内存管理、同步与性能？这个心智模型把 ML 概念与 Vulkan 实现连接起来。

== 本章的读者

本章假定你已完成 Vulkan 主教程，并且能熟练使用计算着色器。你应当知道如何创建命令缓冲区、派发计算工作、管理 GPU 内存并同步操作。如果「管线屏障」和「描述符集」这类术语对你来说已经不成问题，那你就准备好了。

你不需要有机器学习经验，我们会从零开始建立。但如果你用过 PyTorch 或 TensorFlow 这类 ML 框架，你会更容易把那些框架所做的事与你要在 Vulkan 中实现的东西对应起来。

在数学方面，你应当熟悉基础线性代数——向量、矩阵、矩阵乘法。理解函数及其性质会有帮助。微积分不是必需的，不过在解释训练如何进行时（这有助于你理解推理），我们会涉及梯度之类的概念。

== 为什么值得学这些理论？

你也许在想：「我只想跑推理，为什么需要理解这些背景？」这个问题问得合理。原因如下：

*调试*：当你的推理结果出错时——而在某个时刻它一定会出错——你需要知道该从哪里查。是预处理的问题？某个层的实现缺陷？同步问题？理解每一层在数学上应该做什么，能帮你定位出错的地方。

*优化*：神经网络存在瓶颈，而且瓶颈未必在你以为的地方。理解这些运算能帮你判断什么才是真正昂贵的、什么样的优化会有用。你该融合运算吗？改变内存布局吗？换用不同的工作组大小吗？不理解这些运算在做什么，你就无法回答这些问题。

*适配*：新的模型架构不断涌现。如果你掌握了基本原理——卷积做什么、注意力如何工作、归一化为什么重要——你就能在新层类型出现时实现它们。你不会被困在自己最初实现的那几种运算里。

*决策*：有时用自定义 Vulkan 推理是正确选择，有时不是。理解权衡——什么时候自定义实现说得通、什么时候该用现成的库——需要理解你实际在实现什么。

你投入在理解这些基本原理上的时间，会在每一次调试问题、优化性能或实现新模型架构时带来回报。

== 如何使用本章

按顺序阅读各节——每一节都建立在前一节之上。除非你已经对相关概念很扎实，否则不要跳读。本章的设计是从简单到复杂，逐步建立理解。

做例子时不要急。当我们用神经元构建 AND 门时，请自己真正把数学推导一遍。当我们解释卷积如何工作时，请把运算过程跟着走一遍。具体例子正是抽象概念落地的地方。

如果在某个概念上卡住了，这很正常。神经网络涉及很多相互配合的部分。回头重读，把例子再做一遍。这种理解上的投入会在你开始实现时得到回报。

还要记住：本章重在建立心智模型。我们还不实现任何东西——那要留到后面的章节。现在，我们在打基础，让后续的实现能够说得通。
