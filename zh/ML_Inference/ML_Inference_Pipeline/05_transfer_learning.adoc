= 迁移学习

想象你弹了多年吉他，现在开始学钢琴。你不是从零开始——你已经懂得节奏、读谱和双手协调。你是在把知识从一件乐器迁移到另一件乐器。当然，技法不同，但那些基础知识给了你巨大的领先优势。

这正是迁移学习为神经网络做的事。与其为每个新任务从零训练一个模型，不如拿一个已经学到有用模式的模型，把它调整到我们的具体需求上。这是让机器学习变得触手可及的最实用的突破之一。

== 问题：训练代价高昂

我们来诚实地看看从零训练一个神经网络究竟需要什么。时间、金钱、数据和专业能力上的成本高得足以让从零训练超出大多数个人乃至许多机构的能力范围。

=== 计算成本：时间与硬件

以 ImageNet 为例，它是计算机视觉的标准基准之一。它包含 20,000 个类别的 1400 多万张图像。在这个数据集上从零训练 ResNet-50 这样的现代神经网络需要：

*训练时间*：在单块高端 GPU（如 NVIDIA V100）上，在 ImageNet 上训练 ResNet-50 大约需要 2-3 周。也就是 336-504 小时的连续计算。如果你用的是消费级 GPU（如 RTX 3080），可能需要 4-6 周。

而这还是假设第一次就一切顺利。实际上，你会尝试不同的超参数、不同的架构、不同的训练策略。每次实验都是又一次持续数周的训练。训练最先进模型的研究者在找到最佳配置之前，可能要跑上百次实验。

*硬件要求*：你需要显存充足的 GPU。训练 ResNet-50 若要达到合理的批大小，至少需要 11GB 显存。ResNet-152 或 EfficientNet-B7 之类的更大模型需要 16GB 甚至更多。消费级 GPU 往往显存不够，迫使你使用更小的批大小（这会拖慢训练，还可能损害最终精度），或者租用云 GPU。

说到云 GPU：AWS 上的 NVIDIA V100 每小时约 3 美元。以每小时 3 美元训练 ResNet-50 三周就是 1,512 美元。而这只是一次训练。如果你要尝试不同的配置，还得把这个成本乘以实验次数。

*能源成本*：满载的高端 GPU 功耗为 250-350 瓦。连续运行三周大约消耗 125-175 千瓦时。按典型电价计算，电费是 15-25 美元——不算多，但当你跑多次实验时就会累积起来。对于大规模训练（比如 GPT-3，用数千块 GPU 跑数周），能源成本可达数十万美元。

=== 数据要求：数以百万计的样本

从零训练需要海量数据集。ImageNet 有 1400 万张图像。这可不只是 1400 万张随机照片——它们经过仔细标注，每张图像都标注了正确的类别。创建这样一个数据集需要：

*收集*：汇集数百万张图像。对 ImageNet 而言，这意味着从网上抓取图像，这带来了版权和伦理问题。对于你自己的数据集，你需要收集或生成数百万个与任务相关的样本。

*标注*：每张图像都需要一个标签。对 ImageNet 而言，这是通过众包（Amazon Mechanical Turk）完成的，花费数十万美元。即便每个标签只要 0.01 美元，1400 万个标签也要 140,000 美元。而这还是简单的分类——目标检测（绘制边界框）或分割（标注每个像素）的每张图像成本要高得多。

*质量控制*：标签必须准确。这需要每张图像多个标注员、校验和纠错。高质量标签的实际成本往往是原始标注成本的 10-100 倍。

对于你游戏中的武器识别系统，你拥有数百万张带标注的武器图像吗？你负担得起收集和标注它们的成本吗？多半不行。

=== 专业能力要求：不只是按下「训练」

训练神经网络既是科学也是艺术。你需要做出几十个决定：

*架构*：多少层？哪些类型的层？每层多少个滤波器？这些选择会极大影响训练时间和最终精度。做出好的选择需要理解权衡，而且往往要试很多方案。

*超参数*：学习率、批大小、权重衰减、动量、学习率调度、数据增强策略、优化器选择（SGD、Adam、RMSprop？）、初始化策略等等。每一项都对训练有显著影响，而且它们之间以复杂的方式相互作用。找到好的超参数往往需要大量实验。

*训练动态*：损失下降太慢？也许学习率太低。下降太快然后停滞？也许太高。损失剧烈震荡？也许批大小太小。过拟合？你需要更多正则化或数据增强。欠拟合？你的模型可能太简单，或者需要训练更久。

诊断并解决这些问题需要经验。初学者常常要花数周或数月才能学会有效地训练模型。即使是专家，有时也会在特别困难的数据集或架构上挣扎。

=== 机会成本

即使你拥有硬件、数据和专业能力，还有机会成本。你花在从零训练模型上的数周或数月，本可以用在项目的其他方面——游戏设计、图形优化、玩法机制、用户体验。

对大多数应用来说，既然有预训练模型可用，从零训练根本就不划算。这正是迁移学习登场的地方。

=== 一个具体例子：你游戏中的武器识别

我们把它具体化。假设你在做一款游戏，想要一个能从游戏截图中识别 20 种不同武器类型的模型。

*从零训练*：每种武器你都需要数千张图像（总共 40,000 张以上）、数周的 GPU 时间、训练方面的专业能力，以及多轮迭代才能达到不错的精度。总成本：GPU 时间和标注费用 5,000-10,000 美元，再加上你数月的时间。

*迁移学习*：从一个预训练的 ImageNet 模型开始（免费，已训练好）。每种武器收集 50-100 张图像（总共 1,000-2,000 张——你可以从游戏引擎里生成）。在消费级 GPU 上微调几个小时。总成本：几天的你的时间，极少的 GPU 费用。

差别是巨大的。迁移学习让不可能变得可行。

== 洞见：特征可以复用

让迁移学习成立的关键洞见是：神经网络学到的特征往往可以跨任务迁移。这一点初看并不明显——一个训练来识别猫的网络，为什么能帮你识别汽车？但当你理解神经网络实际学到了什么，可迁移性就变得清楚了。

=== 分层特征学习：从简单到复杂

神经网络学的不是铁板一块的「猫检测器」或「狗检测器」。它们学的是特征的层级结构，从简单开始，随着网络加深而逐步变得更复杂、更抽象。

我们来逐层追踪一个典型的图像分类网络学到了什么：

*第 1 层（最靠近输入）*：第一个卷积层学会检测非常基础的视觉基元。如果你把这些滤波器响应的内容可视化，会看到：

- 水平边缘（从暗到亮或从亮到暗的过渡）
- 垂直边缘
- 各种角度的斜边缘
- 颜色斑块（红、绿、蓝区域或特定颜色组合）
- 简单纹理（点、线、渐变）

这些是所有视觉感知的构建单元。任何图像，无论内容如何，都由边缘和颜色区域组成。猫的照片有边缘。汽车的照片有边缘。医学 X 光片也有边缘。这些特征是通用的。

*第 2-3 层（靠前的中层）*：第二层和第三层把那些基础边缘组合成稍复杂一些的模式：

- 角（两条边缘相交处）
- 曲线与弧线
- 简单形状（圆、矩形、三角形）
- 基础纹理（条纹、网格、斑点）
- 颜色组合与渐变

同样，这些是通用特征。角出现在建筑、人脸、车辆和游戏物体中。曲线出现在有机形状、车轮和建筑构件中。这些特征并不特定于任何物体类别。

*第 4-6 层（中层）*：这里开始变得更有意思。中层把简单形状组合成更复杂的模式：

- 重复纹理（毛发、鳞片、织物纹理、木纹）
- 物体部件（眼睛、车轮、窗户、腿）
- 几何模式（对称、重复、对齐）
- 材质属性（光亮与哑光、粗糙与光滑）

这些特征开始变得与领域相关，但仍然有广泛的用途。「毛发纹理」有助于识别猫、狗、熊以及任何毛茸茸的生物。「类似车轮的圆形」有助于识别汽车、自行车和机械。「类似眼睛的图案」有助于识别人类、动物甚至卡通角色的脸。

*第 7-10 层（靠后的中层）*：更靠后的中间层学到更加抽象的模式：

- 复杂的物体部件（人脸、车身、建筑立面）
- 空间关系（眼睛在鼻子上方，车轮在车身下方）
- 上下文模式（草地暗示户外场景，瓷砖暗示室内）
- 风格与外观变化（不同品种的狗、不同型号的汽车）

这些特征更贴近具体任务，但仍能在同一领域内迁移。如果你在 ImageNet（包含许多动物类别）上训练，网络已经学会识别各种动物身体部位、毛发图案和姿态。这些知识能很好地迁移到识别 ImageNet 中没有的新动物物种上。

*最后几层（最靠近输出）*：只有最末尾的层才真正针对具体任务。这些层把前面所有特征组合起来做出最终判断：「这样的特征组合（毛发纹理 + 尖耳朵 + 胡须 + 猫科的脸）意味着猫。」

这些最后的层就是你在迁移学习时替换掉的部分。它们之前的所有内容——所有那些通用特征——你都保留。

=== 这种层级为何会出现

你可能会想：神经网络为什么会学到这种特定的层级？为什么不从一开始就学任务专属的特征？

答案在于神经网络是如何训练的。还记得上一章的梯度下降吗？网络调整权重以减小误差。靠前的层会影响所有后续层，因此它们被优化去学习对许多不同模式都有用的特征。学一次「边缘检测器」并对所有物体复用，要比分别为猫、狗、汽车等学习各自的边缘检测器更高效。

这与人类感知的工作方式类似。你的视觉皮层中有检测边缘的神经元，无论这些边缘属于什么物体。更高层的神经元把这些边缘检测结果组合起来，识别具体物体。进化发现分层特征学习是处理视觉信息的高效方式，而神经网络通过训练也发现了同样的原理。

=== 可视化特征的可复用性

研究者已经开发出可视化神经网络各层所学内容的技术。一种做法是找出能最大程度激活特定神经元的图像。当你对一个在 ImageNet 上训练的网络这样做时：

*第 1 层神经元* 对简单模式有响应——某个神经元可能对任何带水平边缘的图像强烈激活，无论那是猫、汽车还是建筑。

*第 5 层神经元* 对纹理有响应——某个神经元可能对毛发激活，无论那是猫、狗还是熊。另一个可能对金属表面激活，无论那是汽车、飞机还是家电。

*第 10 层神经元* 对特定的物体部件有响应——某个神经元可能对人脸（人、猫、狗）激活，另一个对车轮（汽车、自行车、摩托车）激活，还有一个对文字（标牌、书、屏幕）激活。

关键观察：第 1-10 层学到的是在许多物体类别中都出现的特征。只有最后的层（12 层网络中的第 11-12 层）才专门对应 ImageNet 中的确切类别。

=== 实际含义

正是这种层级结构让迁移学习如此有效。当你拿一个在 ImageNet 上训练的网络去适配识别游戏武器时：

*第 1-3 层*（边缘、角、形状）已经完美适用。武器和其他任何物体一样有边缘和角。

*第 4-7 层*（纹理、材质、物体部件）大部分有用。网络已经学会识别金属纹理、木质纹理、几何图案——这些都与武器相关。

*第 8-10 层*（复杂模式、空间关系）可能需要一些调整。网络学到的是动物身体部位和车辆部件，这些与武器并不直接相关。但识别复杂模式和空间关系的通用能力是可以迁移的。

*最后的层*（具体分类）你完全替换掉。你不想要「猫」或「狗」的输出——你想要的是「剑」「步枪」「弓」等等。

通过保留第 1-10 层、只训练新的最后几层，你利用了价值数百万美元的计算（最初那次 ImageNet 训练），并以最少的额外训练把它适配到你的任务上。

=== 跨领域迁移：能走多远？

你的任务与原始训练任务越相似，能迁移的特征就越多。但迁移学习即使在相当不同的领域之间也能奏效：

*自然图像 → 游戏图形*：效果非常好。即使游戏图形可能是风格化的或渲染出来的，它们仍然有边缘、纹理和物体结构。特征几乎能完全迁移。

*自然图像 → 医学图像*：效果出乎意料地好。X 光片和 CT 扫描看起来与照片差别很大，但它们仍然有边缘、纹理和解剖结构。低层特征完全能迁移，甚至一些中层特征（如「团块状结构」或「线状结构」）也有用。

*自然图像 → 卫星影像*：效果不错。卫星图像的视角和尺度不同，但建筑、道路和植被仍有可识别的纹理和模式。

*英文文本 → 其他语言*：对结构相似的语言（西班牙语、法语、德语）有效。对差异很大的语言（中文、阿拉伯语）效果较差，但仍胜于从零训练。

一般规律：如果你的任务涉及相似的底层模式（图像中的边缘、文本中的词模式），迁移学习会带来显著帮助。领域差异越大，你就越需要微调，而不能只做特征提取。

== 迁移学习如何工作

基本方法出奇地直接：

从一个已在大规模通用数据集上预训练好的模型开始。对计算机视觉来说，这通常是 ImageNet。对自然语言来说，它可能是在书籍和网站上的数十亿词语上训练的。这些模型已经学到了各自领域的基础特征。

然后把预训练模型适配到你的具体任务上。具体做法取决于你的情况——你有多少数据、你的任务与原始任务差别多大、你能分出多少算力。

我们来看看几种主要策略，从最简单到最复杂。

== 特征提取：快速路径

最简单的策略是把预训练模型当作固定的特征提取器。可以这样理解：预训练模型已经学会把原始图像转换成丰富的特征表示。你只需使用这种表示，并在上面加上你自己的分类器。

=== 特征提取如何工作

我们一步步走完这个过程：

*第 1 步：从预训练模型开始*：你下载一个在 ImageNet 上训练好的模型——比如 ResNet-50。这个模型有 50 层，输出 1000 个 ImageNet 类别的概率。

*第 2 步：去掉最后一层*：最后一层是一个有 1000 个输出（每个 ImageNet 类别一个）的全连接层。你去掉这一层。剩下的是一个特征提取器，它接收图像并输出 2048 维的特征向量（对 ResNet-50 而言，倒数第二层有 2048 个神经元）。

*第 3 步：冻结其余所有层*：你把其余所有层标记为「冻结」或「不可训练」。它们的权重在训练中不会改变。它们是固定的特征提取器。

*第 4 步：加上你自己的分类器*：你在顶部加一个新的全连接层。如果你要识别 20 种武器，这一层就有 20 个输出。这一层以随机权重开始——它还什么都不知道。

*第 5 步：只训练新层*：你把训练数据喂进冻结的特征提取器，得到 2048 维特征向量，只训练新的最后层，把这些特征映射到你的 20 个武器类别。

=== 为什么这很快

训练之所以快得多，原因是：

*参数更少*：你不再训练 2500 万个参数（整个 ResNet-50），而只训练大约 40,000 个参数（2048 个输入 × 20 个输出）。参数少了 600 倍。

*需要的数据更少*：参数更少，避免过拟合所需的数据也更少。每个类别几百个样本可能就够了，而不需要数千个。

*迭代更快*：每次训练迭代更快，因为你只为一个层计算梯度，而不是 50 个层。对完整网络可能要训练数天，而只训练最后层只需数小时甚至数分钟。

*不需要 GPU*：你甚至可以在 CPU 上做。用冻结的网络一次性提取特征（可以分批做），保存到磁盘，然后在这些保存好的特征上训练最后层。特征提取这一步用 GPU，但训练这一步轻量到在 CPU 上就能跑。

=== 特征提取最适用的情形

在以下情况下，特征提取是理想选择：

*领域相似*：你的任务与预训练模型处于同一领域。如果模型是在自然照片上训练的，而你处理的也是自然照片（即使物体不同），特征也能很好地迁移。

*数据有限*：你每个类别只有几百个样本，而不是数千个。特征提取比微调需要的数据更少。

*算力有限*：你没有可用于训练的 GPU，或者你需要快速得到结果。特征提取可以在一般的硬件上跑。

*快速原型*：你想快速验证 ML 是否适用于你的任务。特征提取能让你在数小时内而不是数天内得到一个可用的模型。

=== 示例：游戏武器识别

我们把它具体化。你在做一款游戏，想从截图中识别 20 种武器类型。

*数据收集*：你从游戏引擎为每种武器生成 100 张截图（共 2000 张图像）。这需要几个小时。

*特征提取*：你加载预训练的 ResNet-50，去掉最后一层，把所有 2000 张图像过一遍。每张图像变成一个 2048 维特征向量。在 GPU 上这需要几分钟。

*训练*：你训练一个简单的分类器（逻辑回归或一个小神经网络），把这些 2048 维向量映射到你的 20 个武器类别。只有 40,000 个参数要训练，在 CPU 上几分钟就能完成。

*结果*：总共几个小时，你就得到了一个可用的武器识别模型，GPU 使用极少，也不需要深度学习专业能力。

=== 局限

特征提取有这些约束：

*特征不匹配*：如果你的领域与预训练模型的领域差别很大，特征可能就不相关。一个在自然照片上训练的模型，可能无法从医学 X 光片或抽象的游戏图形中提取有用的特征。

*无法调整*：特征是固定的。如果你的任务能从稍有不同特征中获益（也许更强调纹理而非颜色，或关注不同的空间尺度），特征提取无法适应。

*精度上限*：你受限于预训练特征对任务的表示能力。微调通常能通过调整特征把精度提高 5-10%。

尽管有这些局限，特征提取往往仍是正确的起点。它快速、简单，而且对许多任务效果出奇地好。

== 微调：平衡之道

微调更进一步。它不让整个预训练模型保持冻结，而是允许一些靠后的层针对你的具体任务做调整。这比特征提取更灵活，同时仍然利用预训练模型的知识。

=== 微调如何工作

这个过程比特征提取更讲究：

*第 1 步：从特征提取开始*：先做特征提取——冻结整个预训练模型，加上新的最后层，只训练那一层。这给了你一个基线，并确保新层在开始微调前已有合理的权重。

*第 2 步：解冻靠后的层*：从末尾开始逐步解冻层。你可以解冻最后 5 层（共 50 层），或最后 20%，或只解冻最后几个块。具体数量取决于你的数据以及任务与原始任务的差异程度。

*第 3 步：使用更低的学习率*：这至关重要。预训练的权重已经很好——你不想用大的更新把它们毁掉。使用比从零训练小 10-100 倍的学习率。如果你从零训练用 0.01 的学习率，微调就用 0.001 或 0.0001。

*第 4 步：用你的数据训练*：在你的数据集上跑训练。被解冻的层会适应你的具体任务，而冻结的层保留它们的通用特征。

*第 5 步：可选地解冻更多层*：如果你有足够的数据且训练进展顺利，可以解冻更多层，并用更低的学习率继续训练。这种渐进式解冻有助于防止灾难性遗忘（即模型忘掉预训练期间学到的东西）。

=== 为什么更低的学习率很重要

学习率对微调至关重要。原因如下：

*预训练权重已经很好*：模型已经学到了有用的特征。大的学习率更新会破坏这些知识，实质上「忘掉」预训练期间学到的东西。

*小幅调整就够了*：你不是从零学习——你是在对已经不错的特征做小幅调整。一个学会检测「毛发纹理」的神经元可能需要稍微调整，以更好地检测「金属纹理」，但它不需要从头重新学习纹理检测。

*避免灾难性遗忘*：学习率很大时，模型可能会过拟合你的小数据集，忘掉它的通用知识。学习率很小时，它能在适应你任务的同时保留大部分预训练知识。

一种常见策略是 *判别式学习率*：对不同层使用不同的学习率。靠前的层（学习通用特征）用非常小的学习率（或保持冻结），而靠后的层（需要更多调整）用稍大的学习率。例如：

- 第 1-30 层：冻结（学习率 = 0）
- 第 31-40 层：学习率 = 0.0001
- 第 41-50 层：学习率 = 0.001
- 新的最后层：学习率 = 0.01

=== 微调最适用的情形

在以下情况下，微调是理想选择：

*数据量中等*：你每个类别有数千个样本。这足以在不过度过拟合的情况下训练多个层，但不足以从零训练。

*领域略有不同*：你的任务与预训练模型的任务相关但不完全相同。低层特征能迁移，但高层特征需要调整。

*需要更好的精度*：特征提取给了你 85% 的精度，但你需要 90% 以上。微调通常能补上这个差距。

*有 GPU 可用*：微调需要训练多个层，在 GPU 上快得多。在 CPU 上仍然可行，只是更慢。

=== 示例：医学图像分类

我们看一个更有挑战性的例子：把医学图像（X 光片）分类到疾病类别。

*挑战*：X 光片看起来与自然照片差别很大。领域偏移很显著。

*特征提取尝试*：你用 ImageNet 训练的 ResNet-50 试特征提取。它达到 70% 的精度——比随机好，但对医学用途来说还不够。

*微调方案*：
1. 从特征提取的基线开始（70% 精度）
2. 解冻 ResNet-50 最后 10 层
3. 用 0.0001 的学习率训练 20 个 epoch
4. 结果：82% 精度——显著提升

*为什么有效*：靠前的层（边缘、纹理）从自然图像到 X 光片迁移得很好。但靠后的层需要从「动物部件」和「物体形状」调整为「解剖结构」和「疾病模式」。微调允许这种调整，同时保留有用的低层特征。

=== 权衡

微调也有代价：

*需要更多数据*：你需要数千个样本，而不是几百个。数据太少时，微调会过拟合——模型记住你的训练集，在新数据上表现很差。

*训练时间更长*：训练多个层比只训练一个层更久。特征提取只需几分钟的事，微调可能要几个小时。

*对超参数敏感*：学习率、解冻的层数、训练时长都会显著影响结果。找到正确的组合需要实验。

*灾难性遗忘的风险*：如果学习率太高，或数据太少却解冻太多层，模型可能会忘掉预训练知识，表现还不如特征提取。

尽管有这些挑战，微调往往值得。精度提升（通常比特征提取高 5-15%）对生产应用可能至关重要。

== 领域自适应：复杂路径

有时你的任务与预训练模型处于根本不同的领域。也许模型是在自然照片上训练的，而你处理的是医学 X 光片。或者它是在英文文本上训练的，但你需要它处理一种结构完全不同的语言。又或者你处理的是合成游戏图形，看起来与真实照片毫无相似之处。

当领域偏移大到简单微调无法有效应对时，领域自适应技术试图弥合这个差距。

=== 领域偏移问题

当你的数据来自与预训练模型训练数据不同的分布时，就发生了 *领域偏移*。它可以以几种方式表现出来：

*视觉领域偏移*：

- 自然照片 → 医学图像（X 光片、CT 扫描、MRI）
- 真实照片 → 合成渲染（游戏图形、3D 模型）
- 白天照片 → 夜间照片
- 晴朗天气 → 雾天/雨天条件

*文本领域偏移*：

- 正式文本 → 非正式文本（社交媒体、聊天）
- 现代英语 → 历史英语
- 通用文本 → 领域专用术语（法律、医学、技术）

当领域偏移很大时，即使微调也很吃力。模型在一个领域上学到的特征无法很好地迁移到另一个领域。

=== 领域自适应技术

领域自适应是一个活跃的研究领域，方法很多。以下是主要策略：

*对抗式领域自适应*：训练模型产生在源领域（原始训练数据）和目标领域（你的数据）之间无法区分的特征。判别器试图分辨特征来自哪个领域，而特征提取器试图骗过判别器。这迫使模型学习领域无关的特征。

*自训练*：用预训练模型对你的无标注目标领域数据做预测。把高置信度的预测当作伪标签，加入训练集，然后重新训练。重复这个过程，逐步适应目标领域。

*多任务学习*：同时在原始任务（用源领域数据）和你的任务（用目标领域数据）上训练模型。共享层会学到对两个领域都有用的特征。

*风格迁移*：把你的目标领域数据变换成看起来像源领域（或反过来）。例如，把合成游戏图形转换成看起来像自然照片，然后用在自然照片上训练的模型。

=== 何时需要领域自适应

对大多数实际应用，尤其是图形和游戏领域，你并不需要领域自适应。常见任务可用的预训练模型通常与你的领域足够接近，特征提取或微调就能很好地工作。

在以下情况下，你可能需要领域自适应：

*极端的视觉差异*：你的数据看起来与自然照片根本不同。医学影像、卫星影像或高度风格化的游戏图形可能属于这一类。

*没有可用的预训练模型*：你的领域没有预训练模型，而从零训练又不可行。

*微调失败*：你已经用数千个样本试过微调，但由于领域偏移太大，精度仍然很差。

对游戏开发来说，领域自适应很少有必要。即使是风格化的游戏图形，也与自然照片共享足够多的底层特征（边缘、纹理、形状），微调就能很好地工作。

== 为什么这对推理很重要

你可能会想：「我们关注的是推理，不是训练。我为什么要了解迁移学习？」理解迁移学习对成功部署模型至关重要，即使你从不自己训练模型。

=== 模型选择与架构理解

当你浏览 TensorFlow Hub、PyTorch Hub 或 Hugging Face 这类模型库时，会看到模型以其架构（ResNet-50、MobileNet、EfficientNet 等）以及训练或微调所用的数据来描述。

理解迁移学习能帮你做出明智的选择：

*架构一致性*：为你的具体任务微调过的 ResNet-50 与原始 ResNet-50 架构相同。这意味着两者可以共用同一套推理实现。层类型、张量形状和运算完全相同——只有权重值不同。

*模型大小与精度的权衡*：预训练模型以系列形式提供，大小/精度权衡各不相同。MobileNet-V2 有 0.35x 到 1.4x 宽度乘数的多个变体。理解它们都是同一架构、只是容量不同，有助于你根据硬件约束选择合适的一个。

*迁移学习的来源*：标注为「在 COCO 上微调的 ResNet-50」的模型告诉你，它从 ImageNet 预训练开始，然后为 COCO 上的目标检测做了微调。这段历史影响模型擅长什么，以及它期望什么样的预处理。

=== 预处理要求：关键细节

这是许多推理实现出错的地方。推理时的预处理必须 *完全* 与训练时（包括任何微调）的预处理一致。

*归一化数值*：如果模型是用 ImageNet 归一化（mean=[0.485, 0.456, 0.406]，std=[0.229, 0.224, 0.225]）微调的，你在推理时必须使用完全相同的数值。使用不同的归一化会让模型看到分布外的输入，产生垃圾预测。

*缩放策略*：如果模型是用中心裁剪缩放微调的，你在推理时也必须中心裁剪。如果它用了加黑边（保持宽高比），你也必须加黑边。这里不匹配会显著降低精度。

*色彩空间*：如果模型是用 RGB 输入微调的，而你提供 BGR，模型就会在它期望蓝色的地方看到红色。对某些模型，这会彻底破坏预测。

*输入范围*：有些模型期望输入在 [0, 1]，另一些在 [-1, 1]，还有一些在 [0, 255]。用错范围会平移你所有的输入，毁掉精度。

模型的文档应当说明这些要求，但它并不总是完整的。理解模型经历过迁移学习，有助于你通过查看原始预训练模型的要求以及微调期间所做的任何修改，来追溯正确的预处理。

=== 调试与性能预期

理解模型的迁移学习历史，有助于你调试问题并设定现实的预期：

*在你的数据上的精度*：在 1,000 个样本上微调的模型，会比在 100,000 个样本上微调的模型更脆弱。如果你在边缘案例上看到很差的精度，这可能就是原因。

*领域不匹配*：如果模型是在白天户外图像上微调的，而你把它用于夜间室内图像，表现差并不奇怪。理解训练领域有助于你判断何时需要换模型或额外微调。

*失效模式*：模型往往按其训练方式以可预测的方式失效。主要在前脸图像上微调的模型可能在侧面视角上失败。在晴朗天气上微调的模型可能在雾天失败。了解训练数据分布有助于你理解和说明这些局限。

*优化机会*：如果你知道某个模型是用特征提取方式微调的（只改了最后层），你就知道靠前的层与基础模型完全相同。这可能带来优化，比如在多个模型间共享这些层。

== 实践工作流

对本教程系列，以下是你将遵循的典型工作流。理解每一步有助于你做出明智的决定并避开常见陷阱。

=== 第 1 步：选择预训练模型

先浏览模型库，找一个接近你需求的模型：

*可探索的模型库*：

- *TensorFlow Hub*（tfhub.dev）：面向视觉、文本和音频的数千个预训练模型
- *PyTorch Hub*（pytorch.org/hub）：PyTorch 生态中的热门模型
- *Hugging Face*（huggingface.co/models）：在 NLP 方面尤其强，但也有视觉模型
- *ONNX Model Zoo*（github.com/onnx/models）：已是 ONNX 格式的模型
- *Model Zoo*（modelzoo.co）：汇总来自多个来源的模型

*选择标准*：

*任务匹配*：找在与你相似的任务上训练的模型。目标检测看 YOLO、SSD 或 Faster R-CNN。图像分类考虑 ResNet、MobileNet 或 EfficientNet。语义分割看 U-Net 或 DeepLab。

*性能要求*：检查模型的大小和速度。MobileNet 快但精度不如 ResNet。EfficientNet 提供了不错的精度/速度权衡。模型卡片通常会列出在标准硬件上的推理时间。

*硬件约束*：如果你的目标是移动设备，优先选小模型（MobileNet、SqueezeNet）。桌面/服务器则可以用更大的模型（ResNet-152、EfficientNet-B7）。

*许可*：检查许可证。大多数研究模型是开源的（MIT、Apache 2.0），但有些对商业使用有限制。

=== 第 2 步：评估开箱即用的表现

在投入时间微调之前，先在你的数据上测试预训练模型：

*快速评估*：在目标领域的 50-100 个样本上运行模型。表现如何？如果已经有 80% 以上的精度，你可能不需要微调。

*找出失效模式*：模型在什么地方出错？错误是系统性的（总是对某类物体失败）还是随机的？系统性错误说明微调会有帮助。随机错误可能说明你需要更多数据或不同的方法。

*检查预处理*：确认你用的是正确的预处理。许多「模型不工作」的问题其实是预处理不匹配。

=== 第 3 步：必要时微调

如果开箱即用的表现不够，考虑微调：

*收集训练数据*：从目标领域收集样本。对特征提取，每个类别 100-500 个样本可能就够。对微调，目标定在每个类别 1,000-5,000 个样本。

*选择策略*：从特征提取开始（最快、数据需求最少）。如果精度不够，试着微调最后几层。只有当你数据充足时，才解冻更多层。

*使用训练框架*：PyTorch 和 TensorFlow 让微调变得简单。大多数预训练模型都有微调的示例代码。照着这些示例做，并根据你的数据调整。

*仔细验证*：把数据分成训练集、验证集和测试集。训练期间监控验证精度。验证精度停滞时就停止，以避免过拟合。

*记录预处理*：准确记录你在微调时使用的预处理。推理时你需要精确复现它。

=== 第 4 步：导出为推理格式

一旦你有了模型（预训练的或微调过的），把它导出成便于推理的格式：

*选择格式*：

- *ONNX*：最适合跨框架兼容以及桌面/服务器部署
- *TFLite*：最适合移动端部署，尤其是 Android

*导出过程*：

PyTorch → ONNX：

[source,python]
----
import torch
model.eval()
dummy_input = torch.randn(1, 3, 224, 224)
torch.onnx.export(model, dummy_input, "model.onnx")
----

TensorFlow → TFLite：

[source,python]
----
converter = tf.lite.TFLiteConverter.from_keras_model(model)
tflite_model = converter.convert()
with open('model.tflite', 'wb') as f:
    f.write(tflite_model)
----

*验证导出*：用原始模型和导出模型在相同输入上跑推理。确认输出一致（在浮点容差范围内）。导出 bug 很常见，而且可能悄无声息地毁掉你的模型。

*按需优化*：许多格式支持优化流程，可以融合运算、量化权重或剪除不必要的运算。这些能显著减小模型体积并提升推理速度。

=== 第 5 步：用 Vulkan 实现推理

这是本教程系列中我们要花大部分时间的地方：

*加载模型*：解析模型文件（ONNX 或 TFLite），提取网络架构和权重。

*实现运算*：为模型用到的每种运算类型（卷积、矩阵乘法、激活函数等）编写 Vulkan 计算着色器。

*分配 GPU 内存*：为张量创建缓冲区，并智能复用内存以最小化占用。

*执行推理*：按正确顺序派发计算着色器，并配以适当的同步。

*验证结果*：把 Vulkan 推理输出与原始框架的输出做比较。它们应在浮点容差范围内一致。

*优化性能*：做性能分析找出瓶颈，优化内存访问模式，调整工作组大小，并利用 GPU 特有的特性。

=== 这套工作流的美妙之处

这套工作流把关注点漂亮地分开了：

*训练专家* 可以专注于用高层框架（PyTorch、TensorFlow）做训练和微调，不必操心底层 GPU 编程。

*图形程序员* 可以专注于高效的 Vulkan 实现，不需要在训练算法或优化技巧方面有深厚造诣。

*模型格式* 提供桥梁，让任何框架训练的模型都能用任何推理引擎部署。

如果你是懂 Vulkan 的图形程序员，你不需要成为训练算法专家。你可以使用别人训练好的模型，专注于高效地运行它们。反过来，如果你是 ML 研究者，你可以训练模型而不必操心部署细节——Vulkan 实现可以交给别人。

正是这种关注点分离，让现代 ML 部署变得实际可行。

== 小结

迁移学习让你利用预训练模型，而不必从零训练，从而节省时间、数据和计算资源。关键洞见是神经网络的特征往往可以迁移——靠前的层学到的是对许多任务都有用的通用模式。

主要策略有特征提取（只训练新的最后层）、微调（让最后几层适应你的领域）和领域自适应（处理显著的分布偏移）。对大多数实际应用，特征提取或微调提供了简单性与性能之间的恰当平衡。

理解迁移学习有助于你选择合适的模型、匹配预处理要求，并设定现实的性能预期。典型工作流包括：选择预训练模型、可选地微调、导出为推理格式，以及在 Vulkan 中实现高效的 GPU 执行。
