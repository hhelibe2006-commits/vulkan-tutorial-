= 使用 Vulkan 进行机器学习推理：简介

== 简介

欢迎来到「使用 Vulkan 进行机器学习推理」系列教程！本系列探讨 Vulkan 强大的计算能力与现代机器学习推理这一激动人心的交汇点，向你展示如何借助 GPU 完成高性能的 AI 工作负载。

=== 新的疆域

前面的教程系列向你介绍了 Vulkan 的图形与计算基础，而本系列将带你进入机器学习推理的世界——用 Vulkan 计算着色器在 GPU 上高效运行训练好的神经网络。你将学会如何在 ML 框架与底层 GPU 编程之间搭起桥梁，获得高层框架往往无法提供的控制力与性能。

本系列面向已经读完 xref:00_Introduction.adoc[Khronos Vulkan^®^ 教程]、并且对计算着色器和 GPU 编程概念比较熟悉的读者。我们将聚焦于实际实现：加载模型、高效传输数据、在计算着色器中实现神经网络运算，以及针对实时性能做优化。如果你还没有接触过计算管线，请先回到主教程中复习计算着色器相关章节再继续。

=== 该不该自己造轮子？一个务实的视角

在深入用 Vulkan 实现 ML 推理之前，我们先回答最重要的问题：*你真的应该这么做吗？*

对绝大多数应用来说，我们的专业建议很明确：*使用现成的 ML 推理库*。像 TensorFlow Lite、ONNX Runtime、PyTorch Mobile 这样的成熟框架，以及各平台专属的方案（iOS 上的 Core ML、Android 上的 ML Kit、Windows 上的 DirectML）都能提供：

* *经过实战检验的实现* —— 多年的优化与缺陷修复
* *广泛的模型支持* —— 已经实现了数百种算子类型
* *硬件加速* —— 自动使用 GPU、NPU 和专用 AI 加速器
* *活跃的维护* —— 针对新硬件和新技术定期更新
* *生产级可靠性* —— 全球数以百万计的应用在使用

这些库凝聚了数千人年的工程投入。除非你有特定的约束条件导致无法使用它们，否则借用这些成果才是明智的选择。

==== 什么时候自研 Vulkan 实现才合理

那么这个教程为什么还存在？因为确实有一些真实场景，用 Vulkan 自建推理引擎不仅可行，而且是架构上的最佳选择：

*图形集成*：如果你的游戏或图形应用已经用 Vulkan 做渲染，那么把 ML 推理集成进现有的 Vulkan 管线，往往比桥接到一个独立的 ML 框架更高效。你可以避免在不同 GPU 上下文之间传输数据，能够共享内存与同步原语，并保持统一的代码库。

*渲染类 AI 技术*：高斯泼溅、神经渲染等面向图形的 AI 方法通常使用轻量的激活函数和简单的网络结构。这类「简单 AI」方案特别适合用 Vulkan 自行实现，因为计算开销可控，而且与渲染管线紧密集成能带来显著的性能收益。

*嵌入式与资源受限平台*：有些嵌入式系统或专用硬件不支持标准的 ML 框架，但支持 Vulkan。自研实现让你能精确控制内存占用和性能特征，这在资源受限的环境中至关重要。

*新颖的模型架构*：如果你要处理前沿研究模型，其中用到的算子还没被标准框架支持，那么直接用 Vulkan 计算着色器实现，可能比等框架支持或绕过各种限制更快。

*跨平台一致性*：Vulkan 可在 Windows、Linux、Android 上运行，并且越来越多地出现在其他平台上。如果你需要在各种平台上获得完全一致的推理行为，而现有框架表现出细微差异，自研 Vulkan 实现就能提供这种一致性。

*学习与理解*：即使你最终在生产环境中使用的是现成的库，在 Vulkan 层面理解 ML 推理也会让你成为更好的工程师。你会理解性能特征、更有效地调试问题，并做出更好的架构决策。

==== 混合方案

在实践中，许多应用采用混合方案：大多数推理工作负载交给标准 ML 框架，而对特定的性能关键或需要紧密集成的组件使用自研 Vulkan 实现。本教程为这两种情形都做了准备——让你把基础理解得足够深入，从而能就何时采用哪种方案做出有依据的决策。

我们会用一整章讲如何把第三方 ML 库与 Vulkan 应用集成，向你展示如何在框架与 Vulkan 渲染管线之间搭桥。这样你就能为应用的每个部分选择合适的工具。

=== 内容概览

「使用 Vulkan 进行机器学习推理」系列既想让你理解原理，也想让你掌握实用技能。我们将涵盖：

1. *ML 推理基础* —— 机器学习推理是什么、如何工作，以及如何把神经网络看作一系列计算运算。

2. *集成第三方 ML 库* —— 关于如何在 Vulkan 应用中使用成熟的 ML 推理框架（TensorFlow Lite、ONNX Runtime、PyTorch Mobile、DirectML）的完整指南。这是大多数生产应用推荐的做法，我们为此投入了大量篇幅，讲解如何在 ML 框架与 Vulkan 渲染管线之间搭桥。

3. *模型格式与加载* —— 使用 TFLite 和 ONNX 等流行格式，并理解如何加载模型、为 GPU 执行做好准备。

4. *面向 ML 的 Vulkan 计算* —— 用计算着色器实现神经网络运算、高效管理内存、处理同步。

5. *构建自研推理引擎* —— 针对第三方库无法满足需求的专用场景，学习从零开始构建自己的推理引擎。

6. *性能优化* —— 无论使用第三方库还是自研实现，都能掌握最大化吞吐量、最小化延迟、充分发挥 GPU 硬件能力的技巧。

7. *实际应用* —— 把 ML 推理与图形渲染、交互式应用结合起来的真实案例，既演示第三方库集成，也演示自研 Vulkan 实现。

在整个系列中，我们鼓励你尝试不同的模型、试验各种优化策略，并把技术调整到自己的具体用例上。机器学习推理是一个快速演进的领域，在 Vulkan 层面理解它能让你灵活地实现前沿技术——无论是集成现有库，还是构建自研方案。

=== 三条路径的教学方式

本教程采用一种独特的做法：只要可能，我们都会教 *三* 种实现 ML 推理目标的方法。

*路径 1：第三方库* —— 大多数生产应用推荐的做法。你将学习把成熟的 ML 框架（TensorFlow Lite、ONNX Runtime、PyTorch Mobile、DirectML）集成到 Vulkan 应用中，在 ML 推理与渲染管线之间搭桥。

*路径 2：自研 Vulkan 实现* —— 用 Vulkan 计算着色器构建自己的推理引擎。这条路径能让你深入了解 ML 推理在 GPU 层面究竟如何运作，帮助你理解那些第三方库「内部」到底发生了什么。

*路径 3：ML 编译器* —— 使用 ML 编译器（IREE、Apache TVM、OpenXLA、MAX/Mojo）把模型下降为面向 Vulkan 及其他后端的优化内核。这在集成便利性与性能、可移植性之间取得平衡。

为什么要三种都教？因为理解内部机制能让你在生产中更好地使用库和编译器。当你了解卷积如何映射到 GPU 运算、内存如何管理、同步在何处重要时，你就能做出更好的架构决策、更有效地调试问题、更聪明地做优化。熟悉内部核心概念的人，更能理解如何在生产中用好这些工具。

在整个教程中，你会在三种方法上都有实践。基础篇与 Vulkan 计算篇教你亲手实现算子。第三方库篇展示可直接用于生产的方案。ML 编译器部分介绍一条由编译器驱动的路径，它常常能以极小的运行时开销达到接近手写代码的性能。

=== 准备好 ML 工具

要跟着本系列教程动手实践，除了标准的 Vulkan 开发环境之外，你还需要额外准备一些工具：

*Python 与 ML 框架*

大多数 ML 模型都是用基于 Python 的框架训练的。你需要：

- *Python 3.8 或更高版本* —— 用于运行模型转换脚本、使用 ML 库
- *PyTorch 或 TensorFlow* —— 至少一个主流 ML 框架，用来理解模型格式并执行转换
- *ONNX Runtime*（可选）—— 便于处理 ONNX 模型、验证转换结果

*模型转换工具*

不同的模型格式需要不同的工具：

- *TensorFlow Lite 转换器* —— 用于处理 TFLite 模型
- *ONNX 工具* —— 用于 ONNX 模型的修改与优化

*Vulkan 计算环境*

确保你的 Vulkan 开发环境支持计算：

- 确认你的 GPU 支持 Vulkan 计算队列
- 确认你能运行主教程中的计算着色器示例
- 准备好性能分析工具（RenderDoc、Nsight 或类似的），用于性能分析

我们会在第一章给出详细的安装说明，但提前把这些工具准备好，能让你更顺利地跟上进度。重点在实际实现，所以从一开始你就要动手写代码、跑代码。
