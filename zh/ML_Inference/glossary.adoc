= 术语表：机器学习推理

本术语表给出机器学习推理系列教程中使用的关键术语的定义。

[glossary]
激活函数（Activation Function）::
作用于神经网络层输出、引入非线性的数学函数。它让网络能够学习复杂的模式。常见的例子包括 ReLU、Sigmoid 和 Tanh。

基于 AI 的超分（AI-based Upscaling）::
使用机器学习把图像以较低分辨率渲染、再智能放大到较高分辨率的技术（如 DLSS 或 FSR），在保持画质的同时提升性能。

人工神经网络（Artificial Neural Network，ANN）::
受生物大脑的结构与功能启发的计算模型，由相互连接的「神经元」组成，按层处理信息。

反向传播（Backpropagation）::
训练阶段使用的算法，用于计算损失函数相对于网络权重的梯度，从而更新权重以减小误差。

批大小（Batch size）::
单次处理中一起处理的训练样本或推理请求的数量。较大的批大小能提高吞吐量，但会增加内存占用和延迟。

偏置（Bias）::
神经网络层中的一个附加参数，它让激活函数能够平移，帮助模型更好地拟合底层数据。

通道顺序（Channel Ordering）::
张量数据的内存布局。「通道在后」（NHWC）把像素颜色存放在一起（RGBRGB...），而「通道在前」（NCHW）先存放一个通道的所有值，再存下一个（RRR...GGG...BBB...）。

计算着色器（Compute Shader）::
Vulkan 中用于 GPU 通用并行计算的着色器阶段，在实现自研机器学习推理时不可或缺。

卷积（Convolution）::
许多神经网络（尤其是图像处理）中的基本运算，让一个小矩阵（核）在输入上滑动，以提取边缘、纹理等特征。

降噪（Denoising）::
使用机器学习模型去除图像噪声的过程，在实时光线追踪中尤其有用，可以用更少的采样得到干净的结果。

逐元素运算（Element-Wise Operation）::
对张量的每个元素独立应用某个函数的运算。激活函数就是典型的逐元素运算。

特征提取器（Feature Extractor）::
神经网络中识别输入数据模式（边缘、纹理、形状）的初始部分。在迁移学习中，预训练模型的特征提取器常常被复用。

微调（Fine-tuning）::
一种迁移学习技术，在一个新的、更小的数据集上继续训练预训练模型，使其适应特定任务。

FlatBuffers::
一种高效的跨平台序列化库（TFLite 使用它），无需单独的解析步骤即可访问序列化数据，非常适合内存受限的环境。

前向传播（Forward Pass）::
让输入数据穿过神经网络各层以产生输出的过程。推理时只执行前向传播。

冻结层（Frozen Layers）::
预训练模型中在微调期间不更新权重的层。这样能保留原始训练中学到的通用特征。

全连接层（Fully Connected Layer）::
神经网络中的一种层，其中每个神经元都与前一层的每个神经元相连。也称为稠密层（Dense layer）。

GPU（Graphics Processing Unit）::
一种为大规模并行处理而设计的专用硬件加速器，在图形渲染和机器学习工作负载中都非常高效。

梯度下降（Gradient Descent）::
训练期间使用的一种优化算法，沿使损失下降最多的方向迭代调整权重，从而最小化模型的误差。

推理（Inference）::
使用*已训练*的机器学习模型对新的、未见过的数据做出预测或分类的过程。本教程关注在 GPU 上高效推理。

核 / 滤波器（Kernel / Filter）::
卷积运算中使用的小权重矩阵，用于检测输入数据中的特定特征。

延迟（Latency）::
单个输入被模型处理并产生输出所需的时间。低延迟对游戏或交互式 AR 等实时应用至关重要。

层（Layer）::
神经网络中的功能模块，对输入执行某一类特定的计算（例如卷积、池化或激活）。

机器学习（Machine Learning，ML）::
人工智能的一个分支，专注于构建能从数据中学习模式、并通过经验而非显式编程提升性能的系统。

内存复用 / 内存池化（Memory Reuse / Memory Pooling）::
一种优化技术，把中间张量的缓冲区共享或回收，以减少 GPU 内存的总占用。

模型（Model）::
所学模式的数学表示，由网络架构和训练期间学到的权重、偏置构成。

神经可塑性（Neuroplasticity）::
大脑通过建立新的神经连接来重组自身的生物学能力。在人工网络中，这一概念体现为学习过程中连接权重的调整。

归一化（Normalization）::
把输入数据或中间激活值缩放到标准范围（例如 0 到 1，或均值 0、方差 1）的技术，可提升训练稳定性和推理性能。

ONNX（Open Neural Network Exchange）::
一种表示机器学习模型的开源格式，旨在让 PyTorch 和 TensorFlow 等不同框架之间可以互操作。

算子融合（Operation Fusion）::
一种性能优化技术，把多个运算（例如卷积后面接 ReLU）合并到单个计算着色器中，以减少内存带宽和派发开销。

填充（Padding）::
在输入张量边缘添加额外数值（通常是 0）的过程，让卷积核能正确处理边缘并控制输出尺寸。

感知机（Perceptron）::
最简单的人工神经元之一，接收若干二值输入，根据加权和产生单个二值输出。

池化（Pooling）::
一种降采样运算，减小张量的空间维度（宽度和高度），有助于降低计算负载，并使模型对输入位置的细微变化更稳健。

后处理（Postprocessing）::
对模型原始输出所做的一系列运算，把它转换成可用的格式（例如应用 Softmax 得到概率，或把坐标映射回图像）。

预处理（Preprocessing）::
对原始输入数据所做的一系列运算（例如缩放图像、归一化像素值），以便交给机器学习模型。

预训练模型（Pre-trained Model）::
已经在大型通用数据集（如 ImageNet）上训练好的模型，可以直接用于推理，或作为迁移学习的起点。

量化（Quantization）::
降低模型权重和激活值的数值精度（例如从 32 位浮点降到 8 位整数）的过程，用于减小模型体积、提高执行速度。

归约运算（Reduction Operation）::
把张量的多个元素合并为单个值的运算（例如求和、求平均或求最大值），常用于池化层或归一化层。

ReLU（Rectified Linear Unit）::
一种常见的激活函数，定义为 `f(x) = max(0, x)`。它的计算开销低，并有助于在训练中缓解梯度消失问题。

语义分割（Semantic Segmentation）::
给图像中每个像素标注类别的任务（例如「道路」「汽车」「天空」），从而对场景形成细致的理解。

Sigmoid::
一种激活函数，把任意输入值映射到 0 到 1 之间，常用于二分类或特定的门控机制。

跳跃连接 / 残差连接（Skip Connection / Residual Connection）::
神经网络（如 ResNet）中的一种结构元素，让数据绕过一层或多层，有助于在很深的网络中缓解梯度消失问题。

Softmax::
一种激活函数，常用于分类模型的最后一层，把一串数值转换为总和为 1 的概率分布。

步长（Stride）::
卷积或池化运算中核在每一步移动的像素或元素数量。步长大于 1 会导致降采样。

Tanh（Hyperbolic Tangent）::
一种激活函数，把输入值映射到 -1 到 1 之间，常用于循环神经网络。

张量（Tensor）::
多维数值数组（标量、向量和矩阵的推广），是机器学习中的主要数据结构。

TFLite（TensorFlow Lite）::
一个轻量级框架，用于在移动、嵌入式和 IoT 设备上运行机器学习模型，侧重低延迟和小体积。

吞吐量（Throughput）::
模型在单位时间内能处理的输入总数（例如每秒帧数）。高吞吐量对高效处理大规模数据集很重要。

分词（Tokenization）::
把文本切分成更小单元（token，如单词或子词）的过程，这些单元可以转换成数值供模型使用。

训练（Training）::
构建 ML 模型的初始阶段，模型通过调整内部参数（权重和偏置）来最小化误差，从而从数据集中「学习」。

迁移学习（Transfer Learning）::
一种技术，把预训练模型（在大型数据集上训练过）作为新的相关任务的起点，大幅减少训练所需的数据量和时间。

权重（Weights）::
神经网络的可学习参数，决定一个神经元对另一个神经元影响的强度和方向。

中间表示（IR，Intermediate Representation）::
编译器在高层次模型与低层机器码或内核之间使用的一种抽象程序表示。在 ML 中，IR 使得在生成 SPIR-V 或 LLVM 等目标专属代码之前执行常见优化（融合、布局变换、量化）成为可能。

MLIR（Multi-Level Intermediate Representation）::
用于构建领域专属 IR 及其变换的编译器基础设施。IREE 等项目使用 MLIR 表示 ML 图，并把它下降（lower）到 Vulkan（经 SPIR-V）、Metal、CUDA 或 CPU 等后端。

方言（Dialect，MLIR）::
在 MLIR 中，方言是一组运算和类型的集合，用于建模某个特定领域或编译阶段。与本教程相关的例子包括 StableHLO（可移植的 ML 图运算）、Linalg（线性代数构件）、TOSA（可移植的 NN 运算）以及 MHLO（与 StableHLO 密切相关的旧方言）。编译器在生成面向 Vulkan 的 SPIR-V 等目标代码的过程中，会在不同方言之间组合与变换。

StableHLO::
一种标准化的 ML IR（属于 OpenXLA），以可移植的形式捕获模型图。许多框架和工具都能导出到 StableHLO，下游编译器（如 IREE 或 XLA）可以消费它。参见 xref:ML_Inference/Third_Party_Libraries/15_openxla.adoc[OpenXLA：XLA、StableHLO 以及 Vulkan 的定位]。

XLA（Accelerated Linear Algebra）::
一种 ML 编译器（位于 OpenXLA 中），常被 TensorFlow 和 JAX 使用。XLA 把 StableHLO/HLO 下降为面向 CPU、GPU 的优化可执行文件。对于本教程中的 Vulkan 目标，我们使用 IREE 而不是直接使用 XLA。参见 xref:ML_Inference/Third_Party_Libraries/15_openxla.adoc[OpenXLA：XLA、StableHLO 以及 Vulkan 的定位]。

OpenXLA::
一个伞形项目，包含 StableHLO、XLA、IREE 及相关工具链。它统一了导出格式（StableHLO），并提供能为多种后端生成高效产物的编译器与运行时。

SPIR-V::
Vulkan 着色器与计算内核的可移植二进制中间语言。IREE 等 ML 编译器在面向 Vulkan 时会生成 SPIR-V，使模型通过 Vulkan 计算管线执行。
