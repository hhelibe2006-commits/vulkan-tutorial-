= 未来方向：GAN、DLSS 与更多
:pp: {plus}{plus}
:stem: latexmath

你已经打下了扎实的基础。你有了可用的图像分类器、实时相机管线、多级 CI 验证套件、一个「好奇」的 RL 智能体，甚至还有 AI 优化的光线追踪。但在 ML 与图形的世界里，所谓「完成」其实只是下一批实验的起跑线。

这一节是桌面应用章节的收尾，目的是点燃你的想象力。我们来看看几项「更上一层楼」的改进，它们能让你的 Vulkan ML 工具从优秀变得不可或缺。

== 改进 1：生成对抗网络（GAN）

在我们的相机应用里，我们只做分类。但借助**生成对抗网络（Generative Adversarial Networks，GAN）**，你可以实现**实时风格迁移**或**超分辨率**。

=== 「对抗」游戏
GAN 由两个神经网络组成，它们玩的是「猫捉老鼠」的游戏：
1.  **生成器（伪造者）**：试图造出一张看起来真实的图像（例如放大后的帧）。
2.  **判别器（侦探）**：试图分辨真实帧与生成帧。

当两者一起训练时，生成器会变得极其擅长创造逼真的细节——那些传统数学方法（比如双线性放大）永远「发明」不出来的细节。

[latexmath]
++++
\min_{G} \max_{D} V(D, G) = \mathbb{E}_{x \sim p_{data}(x)}[\log D(x)] + \mathbb{E}_{z \sim p_{z}(z)}[\log(1 - D(G(z)))]
++++

=== 面向 Vulkan 的真实应用
*   **风格迁移**：你可以用你 Vulkan 游戏概念美术的「风格」来渲染相机画面。像 link:https://junyanz.github.io/CycleGAN/[**CycleGAN**] 这样的 GAN 能学会在「真实世界」域与你的「游戏美术」域之间转换，而不需要成对的训练数据。
*   **超分辨率**：用 GAN（比如 link:https://arxiv.org/abs/1609.04802[**SRGAN**]）把低分辨率帧放大成清晰的 4K。这对带宽有限的移动端到桌面端串流尤其有用。

== 改进 2：超越降噪——深度学习超级采样（DLSS）

在第 7 章，我们看了 AI 降噪。它在这条产业线上的演进是**深度学习超级采样（Deep Learning Super Sampling，DLSS）**以及类似技术（比如 link:https://gpuopen.com/fidelityfx-super-resolution-2/[**FSR**] 或 link:https://www.intel.com/content/www/us/en/developer/articles/technical/xe-super-sampling-technology-overview.html[**XeSS**]）。

=== 概念
网络不只是去掉噪点，它接收低分辨率、带抖动的输入，重建出高分辨率的帧。它使用**时间反馈**——通过运动矢量「回看」之前的帧，很像我们在光线追踪章节讨论的时间验证。

=== 收益
这让你能以 1080p 渲染 Vulkan 游戏，却以 4K 显示，而性能更接近 1080p。
*   **实现路径**：完整的 DLSS 是专有技术，但你可以试试 link:https://gpuopen.com/fidelityfx-super-resolution-2/[**FSR 2.0/3.0**] 这样的开源等价物（它使用传统的启发式方法），或者用你已有的运动矢量与深度缓冲区，动手做一个基于 CNN 的简单放大器。

== 改进 3：面向智能工程的 RAG

在 CI 验证那一章，AI 能告诉我们一次渲染*是否*坏了。借助**检索增强生成（Retrieval-Augmented Generation，RAG）**，我们可以构建一个系统，告诉我们它*为什么*坏了。

=== 工作原理
1.  **检测**：语义验证器检测到一处视觉异常（例如某个特定的阴影瑕疵）。
2.  **向量检索**：系统提取该 bug 的「语义指纹」，并在一个**向量数据库**中搜索，库里包含你项目的 **Git 历史**、**问题跟踪器**与**着色器源码**。
3.  **上下文注入**：把检测到的错误与你历史中最相关的 3 段代码片段一起交给 LLM。
4.  **生成**：模型生成一份自然语言诊断报告。

**示例报告**：
> 「我检测到阴影闪烁的瑕疵。类似的视觉模式曾在 PR #412 中通过给阴影贴图渲染通道添加同步屏障得到解决。当前 `deferred_renderer.cpp` 第 154 行附近的改动似乎移除了一个类似的屏障。建议：检查阴影通道中的管线屏障。」

=== 实践探索
如果你想动手搭一个，可以看看 link:https://www.langchain.com/[**LangChain**] 或 link:https://www.llamaindex.ai/[**LlamaIndex**]。你可以为整个 Vulkan 项目的源码建立索引，做出一个「图形学导师」机器人，帮初级开发者理解他们的着色器为什么过不了 CI。

== 改进 4：世界模型与想象

在第 6 章，我们的 RL 智能体靠随机点击或跟随好奇心探索应用。我们可以用一个**世界模型**（比如 **DreamerV3**）来改进它。

=== 基于想象的探索
世界模型会学习你 Vulkan 应用的一份「心智模拟」。
*   **潜空间**：智能体不去想象完整的 1080p 帧（那太慢），而是学习应用状态的一种压缩数学表示。
*   **想象**：智能体可以在自己的「脑子里」每秒「模拟」数千次点击，在向真实的 Vulkan 应用发出任何命令之前，先找出最有意思的路径。
*   **收益**：这让智能体能够**规划**。它可以意识到「如果我点这里，大概会卡在这个菜单循环里」，然后选择另一条路径来最大化覆盖。

=== 实践探索
去看看 link:https://danijar.com/project/dreamerv3/[**DreamerV3**] 论文，或 David Ha 的 link:https://worldmodels.github.io/[**World Models**] 项目。为一个基于菜单的 Vulkan 应用实现一个简单的世界模型，是了解生成式 AI 与强化学习交汇处的绝佳方式。

== 改进 5：边缘部署与量化

本章我们构建的模型（MobileNetV2、U-Net）都很大。在本教程的下一部分——**高级主题**——我们将学习如何把这些模型缩小，让它们能在手机与集成显卡上运行而不损失质量。

1.  **INT8 量化**：把 32 位浮点数变成 8 位整数，换来 4 倍加速。
2.  **剪枝**：移除对最终图像没有贡献的「神经元」。
3.  **Vulkan 专用内核**：手写调优的 Slang 着色器以榨取最大吞吐量。

== 前路

机器学习不是优秀图形工程的替代品——它是让图形工程更强的超能力。把这些「未来」概念集成进你的桌面应用，你就在走向这样一个未来：

1.  **软件能自我验证**：你的应用知道自己看起来不对，并能解释为什么。
2.  **探索是自主的**：你不写测试用例，而是放一个智能体去发现它们。
3.  **界面能感知上下文**：你的应用通过相机理解世界，并检索正确的信息（RAG）来帮助用户。

你现在已经拥有构建这些东西的工具。下一步不只是照着教程走——而是打破它、扩展它，去构建我们还没想到的东西。
