= 面向 ML 的 Vulkan 计算：简介

== 简介

你已经了解了机器学习推理是什么、神经网络如何工作，以及如何把第三方 ML 库集成到你的 Vulkan 应用里。现在该深入下去了：用 Vulkan 计算着色器自己实现 ML 推理运算。

本章在 ML 概念与 GPU 实现之间搭起一座桥。我们会以 ML 为重心回顾 Vulkan 计算管线，把基础运算实现为计算着色器，构建一个完整可运行的示例，并确立你在教程余下部分会反复使用的模式。

== 本章涵盖的内容

本章按渐进的方式组织，帮助你的理解从 Vulkan 计算基础逐步走到完整的 ML 运算。

*Vulkan 计算管线回顾*：我们先回顾 Vulkan 的计算管线，但把焦点专门放在 ML 工作负载上。你已经在主教程里学过如何创建计算管线，不过 ML 推理有自己特定的模式与要求。我们会讨论面向张量数据的描述符集布局、不同运算的工作组尺寸，以及对 ML 至关重要的内存访问模式。

*面向 ML 运算的计算着色器*：本章的核心是把 ML 运算实现为计算着色器。我们从简单的开始——ReLU 激活这类逐元素运算——再逐步推进到矩阵乘法和卷积等更复杂的运算。每个运算都会从两个角度解释：数学上它做什么，计算上如何在 GPU 上高效实现。

*数据管理*：ML 推理要搬运大量数据——输入张量、权重、中间激活值、输出。我们会讲如何在 GPU 内存中组织这些数据、如何高效传输，以及如何复用内存以尽量减小占用。理论在这里与实践交汇：理解张量布局、对齐要求和缓冲区管理。

*同步*：神经网络是一串相互依赖的运算。第 2 层必须等第 1 层结束才能开始。我们会讲如何使用管线屏障、内存屏障和执行依赖来保证正确的顺序，同时尽可能最大化并行度。

*完整可运行的示例*：没有实践的理论是空心的。我们会构建一个完整可运行的示例：向量加法。与神经网络相比它看似微不足道，但它以简单到能彻底理解的形式展示了整条管线——加载数据、派发计算工作、同步、读取结果。一旦掌握了这个模式，扩展到更复杂的运算就顺理成章。

== 前置要求

本章假设你已经熟悉 Vulkan 计算管线。具体来说，你应当理解：

*计算管线基础*：创建计算管线、绑定描述符集、派发工作组。如果需要温习，请回看主 Vulkan 教程中的计算着色器章节。

*Slang 计算着色器*：用 Slang 编写计算着色器、理解工作组组织方式、使用共享内存。本章会写多个计算着色器，你需要对这些基础感到自如。

*内存管理*：分配缓冲区、管理设备内存、在主机与设备之间传输数据。ML 推理涉及大量内存管理，你需要理解 Vulkan 的内存模型。

*同步原语*：管线屏障、内存屏障、执行依赖。我们会大量使用它们来协调 ML 运算。

本章全程使用 `vk::raii`（Vulkan-Hpp 的 RAII 封装）来管理资源，与「构建简易引擎」教程保持一致。与 C 风格的 Vulkan API 相比，它提供自动的资源清理和更整洁的代码。

你还应当理解前面各章里的 ML 概念——什么是张量、神经网络层如何工作、卷积和激活函数这类运算在做什么。我们会实现这些运算，所以你需要知道它们该算出什么。

== 本章为何重要

上一章讲了什么时候用第三方库、什么时候自己实现。再提醒一次：大多数生产应用应当使用 ONNX Runtime 或 TensorFlow Lite 这样成熟的库。它们久经考验、经过优化，并且有人维护。

本章走「自己实现」这条路，原因有二。第一，理解 ML 运算如何映射到 GPU 计算能让你更好地使用库——你会理解性能特征、更有效地调试问题，并做出有依据的优化决策。第二，在一些专门场景（与图形紧密集成、渲染 AI、新颖运算、嵌入式约束）中，自己实现才是正确选择。

即使你从不在生产环境部署自己实现，你在这里获得的知识也很有价值。让我们深入技术细节。

== 你将构建什么

读完本章，你将实现：

*面向 ML 运算的完整 Vulkan 计算基础设施*：适用于 ML 工作负载的描述符集布局、管线创建、内存管理和同步模式。

*若干基础 ML 运算的计算着色器实现*：逐元素运算（ReLU、sigmoid）、矩阵运算（矩阵-向量乘法、矩阵-矩阵乘法），以及卷积等更复杂运算的基础。

*可运行的向量加法示例*：一个完整可运行的应用，展示从数据加载到结果验证的整条管线。它可以作为更复杂运算的模板。

*贯穿教程始终的模式与技巧*：适用于所有 ML 运算的内存管理策略、同步模式、调试方法和优化技巧。

== 如何使用本章

本章是动手型的。我们会先解释概念，再实现它们。你应当跟着做，亲手编写并运行代码。不要只是读——把代码敲进去、编译、运行、做实验。

即使你自认为已经掌握，也请从 Vulkan 计算回顾开始。以 ML 为焦点的视角会点出你可能没考虑过的方面。然后按顺序做各个运算——每个都建立在前一个之上。

实现运算时，我们会同时给出数学定义和计算着色器实现。请确保两者都理解。数学告诉你运算该算什么，着色器告诉你在 GPU 上如何高效地算。

向量加法示例至关重要。它简单到可以彻底理解，又完整到足以演示你在更复杂运算中会用到的所有模式。仔细研究它，确保理解每一行，并把它当作你自己实现的模板。
