= 简易引擎——课程模块
:toc: left
:toclevels: 3
:sectnums:

课程模块是自包含的特性扩展，完全位于本 `Courses/` 目录内。
每个模块都会被编译为一个静态库（`SimpleEngineCourses`），并链接到主目标 `SimpleEngine` 中——不会修改任何现有的引擎源文件。

== 可用课程

[cols="2,5",options="header"]
|===
| 模块 | 说明

| xref:../en/Building_a_Simple_Engine/Courses/Opacity_Micromaps/00_introduction.adoc[不透明度微图：面向真实世界的更智能阴影]
| 借助 `VK_KHR_opacity_micromap`，在带 alpha 遮罩的几何体上使用硬件加速的阴影光线。它把任意命中着色器的调用缩减到仅剩恰好位于
alpha 边界处的微三角形。
|===

== 使用课程模块构建

=== 前提条件

* CMake 3.29 或更新版本
* Vulkan SDK 1.3.283 或更新版本（必须包含 `VK_KHR_opacity_micromap` 扩展头文件——推荐 SDK 1.3.296+）
* 支持并声明 `VK_KHR_opacity_micromap` 的 GPU 与驱动

=== 快速开始

[source,shell]
----
# Configure — enable the course modules umbrella option plus the
# Opacity Micromaps module specifically
cmake -B build \
      -DENABLE_COURSES=ON \
      -DENABLE_COURSE_OPACITY_MICROMAPS=ON \
      ..

# Build
cmake --build build --parallel
----

=== CMake 选项

[cols="3,1,4",options="header"]
|===
| 选项 | 默认值 | 作用

| `ENABLE_COURSES`
| `OFF`
| 总开关。任何课程模块要被编译，它都必须为 `ON`。
当它为 `OFF` 时，`Courses/` 子目录会被完全跳过，
构建结果与基础引擎完全一致。

| `ENABLE_COURSE_OPACITY_MICROMAPS`
| `ON`
| 构建不透明度微图模块。除非
`ENABLE_COURSES=ON`，否则该选项无效。启用后，会添加
`ENABLE_COURSE_OPACITY_MICROMAPS` 编译定义，使引擎
启动代码激活 `OmmIntegration`。
|===

=== 仅启用课程，禁用 OMM

[source,shell]
----
# Build courses infrastructure but skip the OMM module
cmake -B build \
      -DENABLE_COURSES=ON \
      -DENABLE_COURSE_OPACITY_MICROMAPS=OFF \
      ..
----

当所有逐课程选项都被禁用时，不会生成 `SimpleEngineCourses` 库，链接步骤为空操作。

=== 全部禁用（仅基础引擎）

[source,shell]
----
cmake -B build -DENABLE_COURSES=OFF ..
----

=== 重新配置已有的构建目录

把相同的标志传给已有的构建树——CMake 会重新执行配置步骤，只更新受影响的构建目标：

[source,shell]
----
cmake -B build -DENABLE_COURSES=ON -DENABLE_COURSE_OPACITY_MICROMAPS=ON
cmake --build build --parallel
----

=== IDE / GUI 配置（cmake-gui / ccmake）

1. 打开 `cmake-gui`（或运行 `ccmake build/`）。
2. 把 `ENABLE_COURSES` 设为 `ON`，然后点击 **Configure**。
3. 把 `ENABLE_COURSE_OPACITY_MICROMAPS` 设为 `ON`（它会在第一次配置之后出现）。
4. 再次点击 **Configure**，然后点击 **Generate**。
5. 像平常一样构建生成的项目。

== 验证构建

启用 OMM 后，配置成功会打印：

----
[Courses] Opacity Micromaps module ENABLED
----

构建成功后，构建树中会生成 `libSimpleEngineCourses.a`（Linux/macOS）或
`SimpleEngineCourses.lib`（Windows），并自动链接到 `SimpleEngine` 中。

运行时，ImGui 面板会显示一个 **Opacity Micromaps** 区域，包含实时统计信息（微图数量、构建耗时、节省的任意命中调用次数）。

== 添加新的课程模块

1. 在 `Courses/` 下创建一个子目录（例如 `Courses/My_Feature/`）。
2. 把它的 `.cpp` 文件添加到 `Courses/CMakeLists.txt` 中的 `COURSE_SOURCES` 列表。
3. 添加对应的 `option(ENABLE_COURSE_MY_FEATURE ...)` 条目。
4. 在 `en/Building_a_Simple_Engine/Courses/` 中为该课程编写文档。
