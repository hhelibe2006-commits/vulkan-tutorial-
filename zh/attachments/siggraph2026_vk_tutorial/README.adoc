= SIGGRAPH 2026：如何编写 Vulkan 应用

本教程的目标是说明如何在 2026 年编写一个 Vulkan 应用。
教程采用了当前推荐的最佳实践：

* 描述符堆
* 着色器对象
* 动态渲染

本教程面向 Vulkan 新手，旨在展示自 Vulkan 1.0 以来的主要改进。

着色器使用 Slang 编写，这是一种由 Khronos Group 主持的现代着色语言。

更多信息参见 link:https://github.com/KhronosGroup/Vulkan-Tutorial/blob/main/en/courses/siggraph2026_vk_tutorial/00_Overview.adoc[概览页面]。

== 构建

=== 前提条件

* C++ 2023 工具链
** Visual Studio 2022（或更新版本）
** Clang 21（或更新版本）与 Ninja
* CMake 3.26 或更新版本
* Git
* Vulkan SDK
* +slangc+，位于 +PATH+ 中，或通过 +-DSLANGC_EXECUTABLE=...+ 提供

[NOTE]
====
本教程可在 Windows 和 Linux 上构建并运行。不支持 Android。
本教程需要大量现代 Vulkan 扩展，包括 +VK_EXT_descriptor_heap+ 与 +VK_EXT_shader_object+。
旧的 Vulkan 驱动将无法运行本教程。
====

=== 配置

无需初始化子模块。

CMake 在配置阶段使用 git 下载所需的第三方库。
其中包括 Sponza 的 glTF 资产。

=== 使用 Visual Studio 编译（Windows）

仓库包含 Visual Studio 2022 和 Visual Studio 2026 预设：

[source,bash]
----
cmake --preset vs2022-debug -DSLANGC_EXECUTABLE="C:/VulkanSDK/1.4.341.1/Bin/slangc.exe"

cmake --preset vs2026-debug -DSLANGC_EXECUTABLE="C:/VulkanSDK/1.4.341.1/Bin/slangc.exe"
----

这会把 Visual Studio 项目文件与可执行文件写入 +build/vs2022+ 和 +build/vs2026+ 下。

构建时，你可以打开 +build/vs2026/vulkan_siggraph.slnx+，也可以在控制台中运行：

[source,bash]
----
cmake --build --preset vs2026-debug
----

=== 使用 Clang 编译（Windows 和 Linux）

仓库包含使用 clang 编译的 CMake 预设：

[source,bash]
----
cmake --preset clang-debug -DSLANGC_EXECUTABLE="C:/VulkanSDK/1.4.341.1/Bin/slangc.exe"
cmake --build --preset clang-debug
----

[NOTE]
====
+-DSLANGC_EXECUTABLE+ 是可选的。如果未提供，CMake 会使用 +PATH+ 中的 +slangc+ 版本。
====

== 运行

[source,bash]
----
.\build\vs2026\Debug\vulkan_siggraph.exe
.\build\clang\vulkan_siggraph.exe
----

== 文件

* +src/main.cpp+、+src/main.h+：包含 Vulkan 代码的主应用。
* +src/util.cpp+、+src/util.h+：一组辅助函数，让教程更易跟随。这些文件中的函数负责解析反射数据、glTF 对象、纹理及相关输入，因此如果你的目标是学习 Vulkan，它们并不那么重要。
* +shaders/+：Slang 着色器。
