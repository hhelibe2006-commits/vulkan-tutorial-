= 结语：角色系统的基础

在这一章里，我们大幅演进了引擎架构，以支撑高级角色管线的需求。我们超越了「构建一个简单引擎」系列中简单、混杂的场景管理，实现了**统一的全局场景图**。

本章的关键成果：

*   **统一层级**：我们消解了世界实体与模型内部节点之间的边界，让跨实体的父子关系与交互成为可能。
*   **脏标记优化**：我们实现了状态追踪系统，消除冗余的矩阵乘法，确保引擎即使在加入数百根骨骼的复杂骨架后依然保持性能。
*   **面向数据设计**：通过改用扁平节点数组加基于索引的连接，我们最大化了 CPU 缓存效率，并让引擎为大规模角色场景做好准备。
*   **双向物理同步**：我们在场景图与物理求解器之间建立了数学桥梁，既能支持运动学动画控制，也能支持动态布娃娃模拟。
*   **元数据驱动的自动化**：我们通过提取 glTF 的「extras」现代化了资产管线，让美术可以直接在自己的 3D 工具里定义物理代理与交互钩子。

这套优化过的场景图是后续一切的基础「神经系统」。没有这个牢固的地基，实现骨骼动画、IK 和物理驱动的布娃娃这些功能，只会得到一个零散、未经优化的代码库。

既然我们的世界能高效管理复杂层级，就准备好让角色活起来了。下一章，我们将实现**高级骨骼与计算蒙皮**，把顶点形变的重活交给 GPU，为富有表现力的高性能动画搭好舞台。

== 验证：该看什么

要验证你的场景图实现：

1.  **拓扑排序**：检查父节点是否总是先于其子节点被加入 `nodes` 向量。
2.  **脏标记传播**：在 `update_transforms()` 里设一个断点。确认父级被修改时，所有子节点的 `WorldDirty` 都被正确置位。
3.  **矩阵正确性**：用一个简单的两节点层级，把你的 `world_matrix` 结果与已知正确的来源（比如 glTF-Validator 的节点变换）做对比。
