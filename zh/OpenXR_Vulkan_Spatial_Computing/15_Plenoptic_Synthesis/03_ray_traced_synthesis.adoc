= 光线追踪合成与微透镜阵列

对于高保真的全息显示，我们使用 **Vulkan 光线追踪（VRT）** 来模拟**微透镜阵列（MLA）**的精确物理光学特性。

== 生态系统视角

本章属于以下类别：**超越 OpenXR 标准**。

标准 OpenXR 运行时围绕传统投影模型构建。你用 Vulkan 的光线追踪管线来模拟复杂的虚拟微透镜光学，实现辐辏-调节解决方案与稀疏光场遍历，其能力超出标准运行时合成器。

== 物理光学：微透镜阵列（MLA）

要理解光线追踪合成，你必须先理解光场相机的工作原理。它们使用**微透镜阵列**——在传感器前方放置由数千个微型透镜组成的网格。在我们的光线追踪管线中，我们把这一过程反过来：

1.  **主光线**：我们从虚拟眼睛向屏幕投射一条光线。
2.  **微透镜求交**：我们模拟光线穿过一个虚拟微透镜。
3.  **折射**：我们根据焦距与曲率计算透镜如何使光线偏折。
4.  **光场查表**：折射后的光线现在指向某个特定的 4D 全光坐标。

运行时通过厂商扩展提供物理 MLA 的焦距、间距与曲率参数，甚至可能为透镜几何体提供预先构建好的加速结构。

== 在 Slang 中实现虚拟透镜

借助 Vulkan 中的 `RaytracingAccelerationStructure`，我们可以模拟光栅着色器无法处理的复杂透镜。我们用指定初始化器配置光线生成通道：

[source,cpp]
----
// Configuring the ray tracing pipeline using designated initializers
vk::RayTracingPipelineCreateInfoKHR pipelineInfo{
    .pNext = &dynamicRenderingInfo, // Link to our dynamic rendering state
    .stageCount = static_cast<uint32_t>(stages.size()),
    .pStages = stages.data(),
    .groupCount = static_cast<uint32_t>(groups.size()),
    .pGroups = groups.data(),
    .maxPipelineRayRecursionDepth = 1,
    .layout = *pipelineLayout
};
----

在我们的 Slang RayGen 着色器中，我们执行物理光学模拟：

[source,slang]
----
// RayGen shader in Slang for plenoptic synthesis
[shader("raygeneration")]
void rayGenMain() {
    uint2 pixelID = DispatchRaysIndex().xy;
    float2 uv = float2(pixelID) / float2(DispatchRaysDimensions().xy);

    // 1. Trace a ray through the virtual microlens optics
    RayDesc ray = generateRayThroughLens(uv);

    // 2. Intersect the ray with our 4D LightField "box"
    float4 color = intersectLightField(ray, lightFieldData);

    // 3. Write the final result to the OpenXR swapchain image
    outputImage[pixelID] = color;
}
----

== 进阶：全息持续性与 MLA 优化

Vulkan 让你能够把合成推进到超出标准的视图相关模型：

*   **时间性全息持续性**：使用 Vulkan 的**光线追踪运动模糊**扩展，你可以通过在预测的显示窗口内投射光线来模拟全息显示的持续性。这能确保运动物体保持清晰稳定。
*   **子组 MLA 求交**：你可以用 Vulkan 的**子组操作**实现高效的射线-圆或射线-六边形求交逻辑，把透镜模拟的计算开销分摊到多个线程上。

== 为什么要用光线追踪？物理保真度

光线追踪让我们能够模拟**辐辏-调节冲突（VAC）**的解决方案。通过实时调整微透镜阵列的虚拟焦距，我们可以改变全息图像的「对焦平面」。这让用户的眼睛能够自然地对焦到远近不同的虚拟物体上，消除眼部疲劳。

此外，与片元着色器中的嵌套循环相比，光线追踪处理**非均匀光场**（例如八叉树）要高效得多。
