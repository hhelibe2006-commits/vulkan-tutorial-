= 多层合成

渲染出**四视图**只是完成了一半。一旦我们有了四个视图（基础眼视图与高细节内嵌视图），还需要把它们送进 **OpenXR 合成器**以最终显示。这正是**多层合成**的用武之地。

== 生态系统视角

本章属于以下类别：**将 Vulkan 与 OpenXR 运行时配合使用**。

提交多个合成层是 OpenXR 中的标准流程。你必须使用运行时的层 API 和 Vulkan 的同步原语，才能把每个投影层正确地交接给合成器。

== 层堆栈：模块化图像

在 OpenXR 中，你不是只提交单张图像，而是提交一个**合成层**数组。合成器会在这些图像送往显示器之前，执行最后一趟高优先级的处理，把它们叠合起来。

1.  **基础层**：标准的 3D 世界（四视图中的索引 0 和 1）。
2.  **内嵌层**：高细节的中央凹数据（索引 2 和 3）。
3.  **叠加层**：保持完全锐利的平面 HUD 或菜单。

[source,cpp]
----
// 1. Defining Composition Layers in OpenXR using designated initializers
XrCompositionLayerProjection baseLayer{
    .type = XR_TYPE_COMPOSITION_LAYER_PROJECTION,
    .layerFlags = XR_COMPOSITION_LAYER_CORRECT_CHROMATIC_ABERRATION_BIT,
    .space = worldSpace,
    .viewCount = 2,
    .views = baseViewsPtr
};

XrCompositionLayerProjection insetLayer{
    .type = XR_TYPE_COMPOSITION_LAYER_PROJECTION,
    .layerFlags = XR_COMPOSITION_LAYER_CORRECT_CHROMATIC_ABERRATION_BIT,
    .space = worldSpace,
    .viewCount = 2,
    .views = insetViewsPtr
};

// 2. Submitting layers to xrEndFrame
std::vector<XrCompositionLayerBaseHeader*> layers = {
    reinterpret_cast<XrCompositionLayerBaseHeader*>(&baseLayer),
    reinterpret_cast<XrCompositionLayerBaseHeader*>(&insetLayer)
};

XrFrameEndInfo frameEndInfo{
    .type = XR_TYPE_FRAME_END_INFO,
    .displayTime = frameState.predictedDisplayTime,
    .layerCount = static_cast<uint32_t>(layers.size()),
    .layers = layers.data()
};
xrEndFrame(session, &frameEndInfo);
----

顺序很重要：列表中的最后一个层会绘制在最上面。

== 遮罩与混合

合成器怎么知道该在哪儿显示高细节的内嵌视图？每个层都指定了一个**投影视图**。对于四视图来说，内嵌层的视图具有更小的 FOV，但相机位姿相同。

合成器使用 FOV 正切值，在数学上把高细节图像「放置」到低细节图像之上，然后执行**软边缘混合**，确保 20 PPD 与 60 PPD 区域之间的过渡对用户不可见。

== 进阶：基于物理的合成与 alpha 混合

Vulkan 让你能超越运行时的默认行为，执行自己的深度感知层合并：

*   **自定义层合并**：运行时通常只支持少数几个层，但你可以用 Vulkan 的**子组操作**与**输入附件**，在交接之前把自己的多个层合并成一张统一的图像，从而绕开运行时的限制。
*   **共享深度缓冲区**：除非使用特定扩展，否则运行时并不知道你各个层的深度值。你可以用 Vulkan 在所有合成层之间创建**共享深度缓冲区**，从而在你的 HUD、世界与内嵌视图之间实现完美的逐像素遮挡。

== 资源同步：多交换链节奏

从引擎的角度看，这意味着我们现在每帧要管理**多个交换链**。

*   **节奏**：我们必须为*每个*交换链（基础层与内嵌层）调用 `xrWaitSwapchainImage` 和 `xrAcquireSwapchainImage`。
*   **Vulkan 同步**：我们的命令缓冲区录制必须确保在调用 `xrReleaseSwapchainImage` 之前，四个视图都已渲染完成并完成布局转换。

这种多层方案让每个层都能拥有自己的分辨率与位深，合成器便可依据场景各个部分的特定需求来优化最终图像。
