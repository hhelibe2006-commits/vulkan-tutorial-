= 用于周边视觉优化的可变速率着色（VRS）

高保真空间计算的核心挑战在于我们需要推送的像素数量之庞大。随着头显朝着单眼 4K、90Hz 或 120Hz 的方向发展，单纯以全分辨率渲染整个场景往往在计算上难以为继。不过，人类视觉给了我们一个独特的优化机会：**注视点渲染**。

我们的眼睛只在一个被称为**中央凹**的很小中心区域感知到高细节。越靠近视野周边，我们分辨精细细节的能力就下降得越明显。本章将探讨如何借助**可变速率着色（VRS）**——一个强大的 Vulkan 扩展——来智能地减少这些周边区域的片元处理，而不牺牲感知到的质量。

可变速率着色让我们能把着色率与像素率解耦。我们不必为每个像素各运行一次片元着色器，而是可以告诉硬件为一组像素（例如 2x2 或 4x4 的瓦片）只运行一次。这种「粗粒度着色」显著降低了 GPU 的 **ALU**（算术逻辑单元）负载，而后者常常是复杂空间着色器的主要瓶颈。

我们将聚焦两种主要策略：

1.  **静态周边优化**：在透镜边缘降低着色率，那里的光学畸变与色差本来就已经模糊了细节。
2.  **动态注视驱动着色**：利用眼动追踪遥测，把高分辨率区域居中到用户当前注视的位置。

到本章结束时，你将理解如何把 **VK_KHR_fragment_shading_rate** 扩展（或它的移动端对应物 **VK_EXT_fragment_density_map**）集成到你的空间管线中，以及如何管理实时更新的着色率图。
