= 逐像素掩码与稳定合成

把虚拟物体与真实世界合成，需要稳定的逐像素掩码，以防止遮挡边界出现「光晕」和「抖动」。

== 生态系统视角

本章属于以下类别：**超越 OpenXR 标准**。

OpenXR 虽然管理基本的环境混合，但标准并不管理基于物理的光传输或泛光掩码。你可以用 Vulkan 的硬件模板管线与计算着色器实现进阶的基于物理的合成与时域稳定性，这是标准 OpenXR 合成器并不会原生协调的。

== 概念：合成方程

在增强现实（AR）中，我们的「背景」是实时摄像头画面（透视）。为了实现逼真的遮挡，我们把语义掩码作为一个**门控函数**来施加。

1.  **硬遮挡**：二值决定（0 或 1）。做法简单，但会在头部移动时产生闪烁的锯齿边缘。
2.  **软遮挡**：在边界处使用平滑的渐变。通过对掩码「羽化」，我们自然地混合虚拟与真实世界，掩盖 ML 通道的瑕疵。

运行时负责选择 alpha 混合模式，并且可能对你提供的 alpha 通道施加后期羽化，以保证锐度。

== 实现基于模板的掩码

在我们的 Vulkan 引擎中，我们用**模板缓冲区**执行高速掩码。这比在片元着色器里分支更高效，因为硬件可以提前丢弃像素。

[source,cpp]
----
// Configuring stencil masking using designated initializers
vk::StencilOpState stencilOp{
    .failOp = vk::StencilOp::eKeep,
    .passOp = vk::StencilOp::eReplace,
    .depthFailOp = vk::StencilOp::eKeep,
    .compareOp = vk::CompareOp::eAlways,
    .compareMask = 0xFF,
    .writeMask = 0xFF,
    .reference = 0x1 // Mark real-world occluders
};

vk::PipelineDepthStencilStateCreateInfo depthStencil{
    .stencilTestEnable = VK_TRUE,
    .front = stencilOp,
    .back = stencilOp
};
----

我们先用 ML 分割掩码把模板缓冲区填好，然后在模板值不等于 0x1 的地方渲染虚拟场景。

== 进阶：基于物理的合成与泛光掩码

Vulkan 让我们能把遮挡质量推到标准 alpha 混合之外：

*   **基于物理的合成**：借助 Vulkan 的**双源混合**，你可以执行复杂的光传输模拟，实时计算物理光线应当如何从虚拟表面反射。
*   **光学泛光掩码**：你可以用 Vulkan **计算着色器**检测明亮的物理光源，并施加自定义的「泛光掩码」，确保虚拟遮挡即使在高对比度环境中也显得坚实。

== 时域稳定性：边缘抖动问题

由于 ML 掩码是逐帧生成的，它们可能会闪烁。为解决这个问题，我们的引擎实现了**时域重投影**：取上一帧的掩码，用当前头部姿态（来自 OpenXR 的预测显示时间）重新投影它。这样就能让现实与虚拟之间的边界保持稳定。
