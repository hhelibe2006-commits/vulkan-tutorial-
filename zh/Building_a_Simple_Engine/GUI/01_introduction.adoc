== GUI：简介

== 简介

欢迎来到「构建简易引擎」系列的「GUI」一章！在上一章实现相机系统之后，现在我们把注意力转向为 Vulkan 应用添加图形用户界面（GUI）。一套设计良好的 GUI 对于构建交互式应用至关重要，它让用户可以控制设置、显示信息并与 3D 场景交互。

本章中，我们会把一款流行的立即模式 GUI 库 Dear ImGui 集成到我们的 Vulkan 引擎中。凭借简单、高效和灵活，Dear ImGui 在游戏与图形行业被广泛使用。它让开发者能够快速创建调试界面、工具和游戏内菜单，而无需应对传统保留模式 GUI 系统的复杂性。

本章将引导你把一套专业的 GUI 系统集成到 Vulkan 引擎中。我们从在 Vulkan 上配置 Dear ImGui 开始，为所有 GUI 功能奠定基础。这次集成需要谨慎管理 Vulkan 资源——我们会创建专用的缓冲区、纹理和管线，让它们与你现有的渲染系统协同工作而互不干扰。

当你既要支持 3D 场景导航又要支持 GUI 交互时，用户输入的处理会变得更复杂。我们将实现一套能够区分「面向 3D 世界」与「面向界面元素」的输入的系统，确保两者都能顺畅交互。

我们不会用面面俱到的控件示例把你淹没，而是聚焦于支撑 GUI 功能的关键集成概念。理解了这些原则，你就能实现项目所需的任何界面元素。

渲染集成带来了有意思的挑战——你的 GUI 需要渲染在 3D 场景之上，又不能打乱现有的管线。我们会通过谨慎管理渲染通道、确保正确的深度测试与混合来解决这个问题。

最后，我们会实现对象拾取，它在 GUI 与 3D 场景之间架起桥梁。该特性让用户可以点击 3D 对象并在界面中看到其属性，从而形成连贯的开发环境。

到本章结束时，你将拥有一套可用的 GUI 系统，可以用它控制相机、调整渲染设置并与 3D 场景交互。这将为后续章节中更高级的特性（如材质编辑器、场景层级和调试工具）奠定基础。

== 前置条件

本章直接建立在「相机与变换」一章之上，因为我们会扩展在那里开发的相机系统，使其与 GUI 交互无缝配合。相机控制需要知道用户何时在与界面元素交互、何时在导航 3D 场景。

你还需要扎实理解若干核心 Vulkan 概念。渲染管线与命令缓冲区的知识至关重要，因为 GUI 渲染需要与你现有的 3D 渲染仔细协调——我们会在管理不同管线状态的同时，把 GUI 绘制调用录制到同一批命令缓冲区中。

缓冲区与图像的创建能力不可或缺，因为 Dear ImGui 需要专用的顶点缓冲区和索引缓冲区来存放其几何体，还需要纹理资源用于字体和任何自定义 UI 纹理。理解描述符集与布局也变得重要，因为我们需要专门为 GUI 渲染创建描述符，且不能干扰你 3D 场景的描述符。

管线创建的知识把这一切串联起来，因为我们要为 GUI 渲染构建一条专门的图形管线，其顶点输入、着色器和渲染状态都与你的 3D 管线不同。

对输入处理概念的基本理解会帮助你跟上进度，因为我们要实现一套双模式输入系统，能够区分 3D 导航与 GUI 交互。
