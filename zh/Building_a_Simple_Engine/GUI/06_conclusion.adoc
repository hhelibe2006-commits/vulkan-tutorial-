== GUI：结语

== 结语

本章我们用 Dear ImGui 为 Vulkan 应用构建了一套完整的 GUI 系统。下面回顾所学内容，并讨论可能的改进方向。

=== 我们学到了什么

* *灵活的 ImGui 配置*：我们探索了如何以跨平台（包括桌面与移动端）可用的方式把 Dear ImGui 接入 Vulkan。实现时不依赖 GLFW 之类的特定窗口系统。

* *通用的输入处理*：我们实现了一套健壮的输入处理系统，把输入事件正确分流给 GUI 或 3D 场景，确保在任何设备上都有流畅的用户体验。

* *UI 元素*：我们学会了创建各种 UI 元素，从按钮、滑块等基础控件，到表格、图表等更复杂的元素，也学会了把它们组织成在桌面与移动平台上都能良好工作的连贯界面。

* *Vulkan 集成*：我们深入了把 ImGui 接入 Vulkan 渲染管线的技术细节，包括命令缓冲区集成、渲染通道配置与性能考量。

有了这些组件，我们为构建可在多平台上运行的 Vulkan 交互式应用打下了坚实基础。无论是在台式机、手机还是平板上使用，用户都能通过直观的界面对设置进行控制、查看信息，并与 3D 场景交互。

=== 可能的改进

我们的 GUI 系统已经可用，但仍有若干可增强之处：

* *针对性优化*：为每个目标平台实现专门的优化，以获得更好的性能。

* *触控友好的 UI*：增强 UI 元素，使其更适合移动平台的触控操作，例如更大的点击区域与手势支持。

* *自适应布局*：创建能自动适应不同屏幕尺寸与方向的布局，从桌面显示器到手机屏幕。

* *自定义样式*：创建与应用视觉风格一致的自定义主题，而不是使用 ImGui 的默认样式。

* *本地化*：为 UI 文本实现本地化系统，从而支持多种语言。

* *无障碍*：通过键盘导航、屏幕阅读器支持、高对比度模式等功能改善无障碍体验。

* *设置持久化*：实现跨应用会话保存与加载 UI 设置的机制。

* *高级布局*：使用 ImGui 的停靠特性构建更复杂的 UI 布局，例如可停靠面板。

* *自定义控件*：针对应用的具体需求开发自定义控件，例如色轮、曲线编辑器或节点图编辑器。

* *性能优化*：对 GUI 渲染做性能分析与优化，尽量降低它对应用整体性能的影响，在资源受限的移动设备上尤其重要。

* *电池效率*：在移动平台上，优化 GUI 渲染以降低耗电。

=== 与其他系统集成

在继续构建 Vulkan 引擎时，可以考虑 GUI 系统如何与其他组件配合：

* *场景图*：如何用 GUI 在不同平台上可视化并编辑场景图的层级？

* *材质系统*：能否用 GUI 做一个材质编辑器，实时调整材质属性，并且界面在桌面与移动端都好用？

* *动画系统*：GUI 可以怎样控制和可视化动画，并为各平台提供合适的控件？

* *物理系统*：GUI 能否提供搭建与调试物理模拟的工具，并针对桌面与移动端采用不同的交互方式？

* *设备特有功能*：如何在保持核心体验一致的前提下利用设备特有功能（例如移动端的触觉反馈）？

回答这些问题，你就能构建出更连贯、更强大的引擎，让 GUI 在多平台上同时服务于开发与运行时功能。

=== 跨平台考量

开发跨平台可用的 GUI 系统时，请留意以下几点：

* *输入方式*：不同平台的主要输入方式不同（鼠标键盘与触控）。

* *屏幕尺寸*：界面需要在小到手机、大到显示器的各种屏幕上工作。

* *性能约束*：移动设备的处理能力与内存通常弱于桌面。

* *电池续航*：在移动设备上，高效的渲染对续航至关重要。

* *平台惯例*：用户期望应用遵循各平台特有的 UI 惯例。

* *测试*：跨平台应用需要在所有目标平台上测试。

=== Vulkan 的其他 GUI 库

本章我们聚焦于 https://github.com/ocornut/imgui[Dear ImGui]，但还有多个 GUI 库可以很好地配合 Vulkan。了解这些选项有助于你为具体需求挑到合适的工具：

* https://github.com/Immediate-Mode-UI/Nuklear[*Nuklear*]：极简的即时模式 GUI 库，体积很小。它专为直接嵌入应用而设计，除 Vulkan 外还支持其他渲染后端。由于简单且开销低，Nuklear 常用于小型独立游戏与工具。

* https://www.qt.io/[*Qt*]：功能全面的 UI 框架，自 Qt 5.10 起支持 Vulkan。Qt 提供更传统的保留模式 GUI 方案，带有丰富的控件与工具。Autodesk Maya 的视口以及多种 CAD 软件都用到了它。

* http://cegui.org.uk/[*CEGUI*]：Crazy Eddie's GUI 系统是一个自由库，为游戏与仿真应用提供窗口与控件。它支持 Vulkan 渲染器，被一些独立游戏引擎使用。

* https://ultralig.ht/[*Ultralight*]：为游戏与应用 UI 设计的轻量、高性能 HTML 渲染器。它可以与 Vulkan 集成，适合希望用 Web 技术构建界面的开发者。

* https://www.noesisengine.com/[*Noesis GUI*]：商业 UI 中间件，支持 XAML，可通过 Vulkan 渲染。它被《Dauntless》等游戏采用，并提供对设计师友好的工作流。

为 Vulkan 应用选择 GUI 库时，可以考虑以下因素：

* 开发范式（即时模式与保留模式）
* 性能需求
* 对设计师的友好程度
* 学习曲线
* 许可与成本
* 平台支持
* 集成复杂度

本章使用的 Dear ImGui 在简单性、性能以及与 Vulkan 集成的便捷性之间取得了良好平衡，因此适合许多开发者。

=== 最后的话

精心设计的 GUI 是打造易用且受众广泛的应用的关键。它是用户与应用交互的主要途径，会显著影响用户体验。理解了如何把 Dear ImGui 接入 Vulkan，并实现了对鼠标、键盘等基础输入都有效的健壮输入处理系统，你已经朝着开发专业品质应用迈出了一大步。

请记住，本章给出的代码只是起点。你可以按自己的需求与应用要求随意修改和扩展。我们的方案足够灵活，既支持大量定制与扩展，又能保持对多个平台的兼容。
