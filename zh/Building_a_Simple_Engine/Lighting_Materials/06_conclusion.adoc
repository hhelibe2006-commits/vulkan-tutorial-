= 结语

本章探讨了 3D 渲染中光照与材质的基础知识，并介绍了采用金属度-粗糙度工作流的基于物理的渲染（PBR）。我们讲解了 PBR 背后的理论，实现了一个可用于 glTF 模型的着色器，还用 Vulkan Ray Query 添加了高质量阴影。我们也学会了如何用推送常量高效地把材质属性传给着色器。

== 我们学到了什么

本章带你走过了在 Vulkan 引擎中实现基于物理的渲染所必需的核心概念。我们介绍了金属度-粗糙度 PBR 工作流，把 glTF 材质属性映射到着色器输入，并用推送常量驱动逐绘制的材质参数，从而避免描述符的频繁改动。你看到了 BRDF 的各个部分如何协同工作以保持能量守恒并产生可信的光照，也看到了如何把着色器接入基于 vk::raii 的管线，让模型端到端地正确渲染。最后，我们集成了硬件加速的光线追踪阴影，以提升真实感。

== 让理解真正落地：这条 PBR 管线的心智模型

从高层看，可以把一帧看成一次线性光计算，它把物理输入变换为可显示的像素：

- 线性空间的输入：强度采用接近物理单位的光源，材质提供的 baseColor/metallic/roughness，以及法线/AO/自发光贴图。所有计算都在线性 HDR 空间中进行，这样不会损失高光余量。
- BRDF 的角色：D 塑造高光（粗糙度控制波瓣宽度），G 在微表面上施加遮罩/自阴影，F 在掠射角提升反射率，并通过 F0 把反射率与材质类型联系起来。能量守恒把镜面项（kS）与漫反射项（kD）关联起来，使总输出不超过入射的能量。
- 材质参数作为调节杆：
  * 粗糙度：加宽或收窄镜面波瓣，同时通过 G 降低峰值强度。
  * 金属度：在电介质行为（有色漫反射 + 中性镜面反射）与导体行为（有色镜面反射、无漫反射）之间交叉过渡。
  * 基础颜色：对电介质是漫反射反照率，对金属则是有色镜面反射。
- 法线/AO/自发光的上下文：法线贴图扰动局部朝向以增加细节，AO 衰减间接光/环境光以避免凹陷处显得平板，自发光添加与光照无关的辉光。
- 输出阶段：在叠加环境光/间接光与直接光照之后，用色调映射器（例如 Reinhard/ACES）压缩 HDR，最后才做 gamma 校正以匹配显示器。gamma 只能做一次（要么在着色器里做 pow，要么使用 sRGB 帧缓冲区）。

当结果看起来不对时，可以按下面这个推理循环排查：

1. 确认色彩空间与顺序：线性光照 ➜ 色调映射 ➜ gamma。检查你是否做了重复的 gamma 校正。
2. 探查 BRDF：所有东西都像塑料？可能是粗糙度太低，或者 kD 没有随金属度降低。高光暗淡发浑？可能是粗糙度太高或曝光太低。
3. 验证法线/TBN：绿色通道反转或切线的手性错误会导致异常的着色和接缝。
4. 校准曝光/色调映射：如果白色被硬性截断，就加入曝光控制，和/或改用 ACES/Hable 以获得更平滑的滚降。
5. 谨慎使用 AO 与自发光：AO 应影响环境光/IBL，而不是直接镜面反射；自发光是叠加项，与光源无关。

这个心智模型能帮你预测任一输入的改动会如何沿管线传递并最终出现在屏幕上——这才是「理解」的核心，而不只是照着清单操作。

== 可以改进的方向

我们的 PBR 通道是一个扎实的基线。收益最大的升级是基于图像的光照（用环境贴图为环境光/间接光提供来源），以及若干材质扩展（例如清漆或各向异性）。在性能方面，当光源数量增长时，可以考虑分簇前向或延迟路径。如果要搭建 HDR 链路，泛光和更具电影感的色调映射器（ACES/Hable）可以让最终呈现更完整。
