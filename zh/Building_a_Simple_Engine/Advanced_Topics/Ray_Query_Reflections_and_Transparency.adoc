== 光线查询反射与透明度

光线查询让你无需采用完整的光线追踪管线，就能为渲染器加入反射与折射，过程相当直接。在本引擎中，Ray Query 模式的计算着色器已经计算主可见性；我们在这个着色器上扩展出*次级光线*，以处理反射性和透射性材质。

本页讲解这套设计，以便你在自己的项目中复用。

=== 两个开关，一个清晰的心智模型

Ray Query 模式暴露两个特性开关：

* *反射*：从第一次命中处发射一条反射光线。
* *透明度／折射*：为透射性材质发射一条折射光线。

还有一个小的质量旋钮：

* *最大次级弹射次数*：`0` 完全禁用次级光线；`1` 启用单次弹射。

限制弹射次数的目的是让性能保持可预测，同时仍能演示光线查询如何叠加进基于物理的着色模型。

=== 反射光线（一次弹射）

在第一次命中表面时，我们有：

* 出射视线方向 `V`
* 表面法线 `N`
* 材质参数（粗糙度、金属度，以及 Fresnel 基础反射率）

反射方向就是标准的几何反射：

`R = reflect(-V, N)`

在计算着色器中，我们从沿法线的小偏移处发射新光线，以避免自相交：

* 原点：`P + N * eps`
* 方向：`R`

如果反射光线命中物体，我们就用与主光线相同的 PBR 路径对该命中点着色。如果没有命中，则使用稳定的天空／背景函数。

最终的反射贡献由 Fresnel 加权，并按粗糙度衰减：

* 掠射角反射更强
* 粗糙表面反射更弱

这样结果既直观又稳定。

=== 薄玻璃折射（一次弹射）

对于透射性材质，我们实现了一个「薄玻璃」模型：

* 折射光线给出*透过*表面的视图
* 反射光线给出表面*上*的视图
* Fresnel 在两者之间混合

我们用 Snell 定律计算折射，并配一个简单的全内反射回退。

折射光线使用：

* 原点：`P + refrDir * eps`（沿折射方向偏移）
* 方向：`refrDir`

透射结果先通过 Fresnel 与反射混合，再按材质的透射因子混入基础表面颜色。

=== Alpha 遮罩表面（植被）

许多真实场景用*alpha 遮罩*来处理植被和薄几何。alpha 遮罩与常规混合不同：

* 每个像素上表面要么存在、要么不存在
* 判断由 baseColor 的 alpha 纹理和 `alphaCutoff` 驱动

在传统光线追踪管线中，alpha 遮罩通常实现在 any-hit 着色器里。使用光线查询时，我们可以通过控制哪些候选相交被提交来实现同样的思路。

做法是：

1. 对带 alpha 遮罩的实例允许非不透明候选。
2. 对每个候选三角形命中：
   * 计算候选 UV
   * 采样 baseColor 的 alpha
   * 仅当 `alpha >= alphaCutoff` 时接受该候选

这样能让主光线中带遮罩几何的可见性保持正确，同时也让反射／折射保持一致，因为它们使用同一套遍历例程。
